1왜 저량과 유량인가

많은 사람이 “들어오는 양이 줄면 쌓인 양도 줄 것”이라고 착각합니다. 쌓인 양은 들어오는 양과 나가는 양의 차이로만 변합니다.

1.1욕조 문제

욕조에 수도꼭지로 물이 들어오고 배수구로 나갑니다. 처음 10분 동안 수도를 세게 틀었다가 점점 줄입니다. 물 높이는 언제 가장 높을까요? 들어오는 양이 가장 많을 때가 아니라, 들어오는 양이 나가는 양과 같아지는 순간입니다. 그 전까지는 줄어드는 중이어도 들어오는 쪽이 더 많으니 계속 차오릅니다.

욕조: 유량과 저량

위: 들어오는 양(파랑)과 나가는 양(주황), 분당 리터. 아래: 욕조의 물(저량). 세로선은 두 유량이 같아지는 순간입니다.

같은 착각이 현실에서도 자주 일어납니다. “신규 확진자 증가 속도가 줄었다”는 뉴스는 확진자 수가 줄었다는 뜻이 아닙니다. “적자 폭이 줄었다”는 빚이 줄었다는 뜻이 아닙니다. 저량(쌓인 양)과 유량(흐르는 양)을 구분하는 것이 시스템 다이내믹스(SD)의 출발점입니다.

1.2개체 대신 수로 보기

3편에서는 여우와 토끼 한 마리 한 마리가 격자 위를 움직이고, 배고프면 굶고, 만나면 잡아먹혔습니다. 그런데 궁금한 것이 “토끼 수가 어떻게 출렁이는가”뿐이라면 이렇게 물을 수도 있습니다. 토끼가 R마리, 여우가 F마리일 때 1주일 동안 평균 몇 마리가 태어나고 몇 마리가 잡아먹힐까? 이 평균 비율로 수를 갱신하면, 개체 없이 수만으로 시뮬레이션할 수 있습니다.

이것이 SD의 관점입니다. 개체의 차이와 공간을 버리는 대신, 몇 개의 식으로 전체 흐름을 보고 피드백 구조를 분명하게 드러냅니다. 계산도 매우 빠릅니다. 버린 것의 대가는 2.4절에서 확인합니다.

2이론

SD 모델의 재료는 저량, 유량, 그리고 유량을 정하는 규칙 셋뿐입니다. 규칙이 저량에 다시 의존하면서 피드백이 생깁니다.

2.1저량, 유량, 오일러 한 걸음

저량(stock)은 어느 순간 쌓여 있는 양입니다. 물, 인구, 재고, 감염자 수. 유량(flow)은 단위 시간당 저량을 바꾸는 흐름입니다. 출생률, 주문량, 감염 속도. SD 그림에서는 저량을 상자로, 유량을 밸브가 달린 굵은 화살표로 그립니다. 컴퓨터는 시간을 Δt만큼씩 잘게 쪼개 다음 식을 반복합니다.

2.2강화 루프와 균형 루프

강화 루프 (R)

저량이 클수록 유입이 커지고, 그래서 저량이 더 커집니다. 은행 이자, 입소문, 인구 증가. 기하급수적 성장(또는 붕괴)을 만듭니다. 성장률이 r이면 두 배가 되는 데 약 0.69/r의 시간이 걸립니다.

균형 루프 (B)

저량이 목표에서 멀수록 그 차이를 줄이는 흐름이 커집니다. 식어 가는 커피, 온도 조절기, 목표 재고를 맞추는 주문. 목표에 점점 느려지며 다가갑니다. 남은 차이가 절반이 되는 데 약 0.69 × τ의 시간이 걸립니다.

두 루프의 모양

왼쪽: 강화 루프 dS/dt = r·S (동아리 회원 10명에서 시작). 오른쪽: 균형 루프 dT/dt = −(T − 실온)/τ (90도 커피, 실온 22도).

2.3두 루프가 만나면: 로지스틱 성장

현실에서 강화 루프만 영원히 도는 시스템은 없습니다. 풀밭이 한정된 토끼, 학과 학생 수가 정해진 동아리처럼 커질수록 브레이크가 걸립니다. 강화 루프에 균형 루프가 붙으면 S자 곡선이 나옵니다.

2.4포식자와 피식자: 3편을 식 두 줄로

토끼 R과 여우 F를 두 저량으로 둡니다. 토끼는 스스로 불어나고 여우에게 잡아먹힙니다. 여우는 토끼를 먹은 만큼 불어나고 스스로 죽습니다. 로트카-볼테라 모델입니다.

SD와 확률적 개체 모델 비교

왼쪽: 시간에 따른 토끼(초록)와 여우(주황). 오른쪽: 위상 평면(가로 토끼, 세로 여우). 진한 선은 SD(미분방정식), 흐린 선들은 같은 비율을 개체 단위의 확률적 사건으로 돌린 실행 10개입니다. 여우 증가 δ는 0.01로 고정했습니다.

SD 모델은 영원히 같은 고리를 돕니다. 여우가 0.3마리가 되어도 다시 살아나죠. 실제 동물은 0.3마리일 수 없습니다. 개체 단위로 돌리면 수가 적어지는 골짜기에서 우연히 0이 되어 멸종하는 실행이 생깁니다. 3편에서 섬을 작게 만들면 공존 확률이 크게 떨어졌던 것이 바로 이 효과입니다.

“토끼 수용력” 상자를 켜면 고리가 안쪽으로 감기며 평형점에 수렴합니다. 토끼 번식에 균형 루프(2.3절)를 붙였기 때문입니다. 모델 구조의 작은 차이가 출렁임이 계속되느냐 멎느냐를 바꿉니다.

3편과 비교SD는 수가 많고 잘 섞여 있을 때 ABM 평균의 좋은 근사입니다. 수가 적을 때, 공간적으로 뭉쳐 있을 때(토끼가 여우를 피해 숨을 곳이 있을 때), 개체 차이가 중요할 때 둘은 갈라집니다.

2.5SIR 감염병 모델

인구를 감수성자(S, 아직 안 걸림), 감염자(I), 회복자(R, 면역) 세 저량으로 나눕니다. 감염은 S와 I가 만나서 일어나고, 감염자는 평균 1/γ일 뒤 회복합니다.

dS/dt = −β(S/N)I, dR/dt = γI가 나머지 두 식입니다. 세 식을 더하면 0이므로 S + I + R = N이 항상 유지됩니다. 이런 보존 관계는 8편에서 프로그램 검증에 아주 유용하게 씁니다. 3.3절에서 이 모델로 캠퍼스 대응 정책을 실험합니다.

2.6지연과 진동

균형 루프는 목표에 부드럽게 다가가야 하는데, 현실에서는 자주 목표를 지나쳤다가 되돌아오며 출렁입니다. 원인은 지연입니다. 샤워 물 온도를 맞출 때 수도꼭지를 돌리고 몇 초 뒤에야 온도가 바뀌면, 성급한 사람은 너무 많이 돌렸다가 다시 반대로 돌립니다. 재고 관리에서는 이렇게 나타납니다.

3예제와 사례 연구

세 사례 모두 실제 데이터와 맞춰 보거나 현실 정책을 실험할 수 있는 형태입니다.

3.1동아리 앱의 입소문쉬움

학과 학생 400명에게 새 동아리 앱을 알립니다. 사람들은 두 경로로 가입합니다. 공지를 보고 스스로(광고 효과 p), 그리고 이미 쓰는 친구를 보고(입소문 효과 q). 가입자 A가 저량이고, 가입 속도가 유량인 배스 확산 모델입니다.

dAdt = (p + q AM)(M − A)

점은 첫 30일 동안 실제로 센 누적 가입자라고 합시다(가상 데이터). 슬라이더로 p와 q를 조정해 곡선을 점에 맞춰 보세요. 오차(점과 곡선 차이의 제곱합)가 작을수록 잘 맞는 것입니다. 이렇게 모수를 데이터에 맞추는 일을 보정(calibration)이라고 하며, 8편에서 체계적으로 다룹니다.

배스 모델을 데이터에 맞추기

위: 누적 가입자(선은 모델, 점은 관측). 아래: 하루 신규 가입자. 맞춘 뒤 60일 뒤의 모습을 예측해 보세요.

p가 크고 q가 작으면 곡선이 처음부터 꾸준히 오르고(공지가 주효), q가 크면 처음엔 느리다가 폭발적으로 오르는 S자가 됩니다(입소문이 주효). 맞춘 모수를 보면 어떤 홍보에 힘써야 할지에 대한 단서도 얻습니다. 실제로 해 보려면 동아리 단톡방이나 학과 행사 신청자 수를 매일 기록하면 됩니다.

3.2원두 재고와 채찍 효과중간

커피점은 하루 20kg의 원두를 쓰고, 목표 재고는 60kg입니다. 주문한 원두는 L일 뒤 도착합니다. 10일째부터 시험 기간이라 수요가 하루 26kg으로 늘어납니다. 2.6절의 주문 규칙으로 운영하면 재고가 어떻게 움직일까요?

재고와 주문

위: 재고(kg). 0 아래로 내려가면 품절입니다. 아래: 수요(회색)와 주문량(색).

w = 0(주문해 둔 양을 잊음)에 지연이 길고 τ가 짧으면 재고가 크게 출렁이고, 주문량의 출렁임이 수요의 출렁임보다 훨씬 커집니다. 공급망 위로 갈수록 출렁임이 커지는 이 현상을 채찍 효과(bullwhip effect)라고 합니다. w를 1로 올리거나 τ를 늘리면 진동이 잦아듭니다. 해결책은 더 빨리 반응하는 것이 아니라, 이미 오고 있는 것을 기억하는 것입니다.

3.3캠퍼스 독감 대응실전

학생 8,000명의 캠퍼스에 독감 환자 5명이 생겼습니다. 보건소는 세 가지 대책을 검토합니다. 학기 초 예방접종 캠페인, 감염자가 일정 수를 넘으면 2주 비대면 수업(접촉 감소), 그리고 아무것도 안 하기. 아래 모수는 설명을 위한 예시 값입니다. 실제 분석에서는 지역 보건 자료로 R₀와 감염 기간을 추정해야 합니다(4편, 8편).

SIR로 대책 비교

감염자(I), 감수성자(S), 회복자(R) 수. 색칠한 구간은 비대면 수업 기간입니다.

몇 가지를 확인해 보세요. 예방접종률을 1 − 1/R₀ 근처까지 올리면 유행이 거의 시작되지 않습니다. 비대면 수업은 정점을 낮추지만, 너무 일찍 시작해서 끝나면 2주 뒤에 유행이 다시 올라옵니다. 감수성자가 그대로 남아 있기 때문입니다. 정점 높이(보건소가 감당할 동시 환자 수)와 최종 감염 규모(총 환자 수) 중 무엇을 줄이고 싶은지에 따라 좋은 대책이 달라집니다.

이 모델의 가장 큰 가정은 “모두가 모두와 고르게 섞인다”는 것입니다. 실제 캠퍼스에는 기숙사, 학과, 수업이라는 구조가 있어서 같은 수업을 듣는 학생끼리 훨씬 자주 만납니다. 이 구조가 결론을 바꾸는지 알고 싶다면 학생을 에이전트로, 수업과 기숙사를 접촉 네트워크로 둔 ABM이 필요합니다. 좋은 프로젝트 주제입니다(9편).

def sir(N=8000, I0=5, R0=1.8, days_infectious=4, vaccinated=0.0, dt=0.1, days=180):
    gamma = 1 / days_infectious
    beta = R0 * gamma
    S, I, R = N * (1 - vaccinated) - I0, I0, N * vaccinated
    out = []
    for step in range(int(days / dt)):
        new_inf = beta * S * I / N * dt      # S → I 유량 × Δt
        new_rec = gamma * I * dt             # I → R 유량 × Δt
        S, I, R = S - new_inf, I + new_inf - new_rec, R + new_rec
        assert abs(S + I + R - N) < 1e-6     # 보존 관계로 검증 (8편)
        out.append((step * dt, S, I, R))
    return out

traj = sir()
peak = max(traj, key=lambda row: row[2])
print(f"정점 {peak[0]:.0f}일째, 동시 감염자 {peak[2]:.0f}명, 최종 회복자 {traj[-1][3]:.0f}명")

직접 오일러 방법으로 푼 SIR입니다. 실무에서는 scipy.integrate.solve_ivp처럼 오차를 스스로 조절하는 적분기를 씁니다(7편).

4.1SD, DES, ABM 비교

기본 단위저량과 유량 (수, 양)개체가 흐르는 자원과 대기열스스로 판단하는 개체

4.2앞뒤 편과의 연결

3편과로트카-볼테라는 3편 생태계의 평균장(mean-field) 근사입니다. 수가 적거나 공간 구조가 중요하면 둘의 결론이 갈라집니다.

4편과 5편SD 모델은 보통 결정적이라 반복 실행이 필요 없습니다. 하지만 모수(R₀, 배송 지연)가 불확실하면, 모수를 분포에서 뽑아 여러 번 돌리는 몬테카를로 민감도 분석을 해야 합니다.

7편으로오일러 방법과 Δt 선택은 연속 시스템 시뮬레이션의 핵심 문제입니다. 2.3절에서 본 Δt가 클 때의 엉뚱한 진동을 7편에서 정면으로 다룹니다.

8편으로3.1절의 보정, 2.5절의 보존 관계(S + I + R = N)를 이용한 검증, 3.3절의 정책 비교가 모두 8편의 주제로 이어집니다.

4.3요약과 연습 문제

저량과 유량
저량은 유입 − 유출로만 변한다. S(t+Δt) = S(t) + (유입 − 유출)Δt.
피드백
강화 루프는 기하급수, 균형 루프는 목표 추구. 둘이 만나면 S자.
대표 모델
로지스틱, 로트카-볼테라, SIR(R₀ = β/γ, 집단 면역 1 − 1/R₀), 배스 확산.
지연
균형 루프에 지연이 끼면 진동한다. 파이프라인을 기억하면 줄어든다.
SD의 한계
평균만 다루므로 작은 수의 우연, 공간, 개체 차이를 놓친다.
1. 은행 예금이 연 5%로 복리 성장합니다. 두 배가 되는 데 대략 몇 년이 걸릴까요?

배가 시간 ≈ 0.69/r = 0.69/0.05 ≈ 14년입니다. 흔히 “70의 법칙”(70 ÷ 이율%)이라고 부릅니다.

2. R₀ = 2.5인 감염병의 집단 면역 문턱은? 백신 효과가 80%라면 몇 %가 접종해야 할까요?

문턱은 1 − 1/2.5 = 0.6, 즉 60%가 면역이어야 합니다. 백신이 80%만 효과가 있다면 0.6/0.8 = 75%가 접종해야 합니다.

3. 로트카-볼테라에서 α = 0.6, β = 0.02, δ = 0.01, γ = 0.5일 때 평형점은?

dR/dt = 0에서 F* = α/β = 30, dF/dt = 0에서 R* = γ/δ = 50입니다. 토끼 번식이 빨라지면(α 증가) 토끼가 아니라 여우의 평형 수가 늘어난다는 점이 이 모델의 유명한 역설입니다.

4. 재고 진동을 줄이기 위해 “더 자주, 더 빨리 주문하라(τ를 줄여라)”는 지시가 내려왔습니다. 좋은 생각일까요?

대개 역효과입니다. 지연이 있는 균형 루프에서 반응을 서두르면 목표를 더 크게 지나쳐 진동이 커집니다. 3.2절 위젯에서 w = 0, τ = 1로 확인해 보세요. 이미 주문한 양을 기억하는 것(w를 높이기)이나 배송 지연을 줄이는 것이 효과적입니다.
