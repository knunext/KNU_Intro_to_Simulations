미분과 적분은 함수를 다루는 기술입니다. 그 전에 함수를 옮기고 늘이는 법, 지수와 로그, 삼각함수, 끝없는 합처럼 로봇 식에 계속 나오는 재료를 먼저 챙깁니다.

넣으면 나오는 규칙: 함수와 그래프

쓰인 곳확률과 통계 101의 정규분포PID의 모터 포화운동 모델의 f(x, u)센서 보정
먼저, 수식 없이

자판기에 돈을 넣고 버튼을 누르면 음료가 하나 나옵니다. 같은 돈, 같은 버튼이면 늘 같은 음료가 나오죠. 이렇게 넣은 것마다 나오는 것이 하나로 정해진 규칙이 함수예요. 넣는 것을 입력 x, 나오는 것을 출력 y라 하고 y = f(x)라고 씁니다.

로봇에는 함수가 가득합니다. 적외선 거리 센서는 ‘전압을 넣으면 거리가 나오는’ 함수이고, 모터 드라이버는 ‘명령을 넣으면 실제 힘이 나오는’ 함수예요. 모터는 일정 이상은 못 내니 명령이 커져도 출력이 평평해집니다(포화). 운동 모델 실습의 f(x, u)도 ‘지금 상태와 명령을 넣으면 변하는 빠르기가 나오는’ 함수였어요.

함수를 그림으로 그린 것이 그래프입니다. 가로축에 입력, 세로축에 출력을 찍어 이은 선이에요. 그래프를 옆으로 옮기거나 늘이는 법만 알면, 정규분포처럼 처음 보는 식도 ‘아는 모양을 옮기고 늘인 것’으로 읽을 수 있습니다.

한 줄로함수는 입력 하나에 출력 하나를 정해 주는 규칙이고, 그래프는 그 규칙의 그림입니다. 모양을 옮기고 늘이는 네 손잡이(a, b, c, d)만 알면 많은 식이 읽혀요.

조금 더 정확하게

가장 단순한 함수는 직선 y = ax + b입니다. a는 기울기로, x가 1 늘 때 y가 a만큼 늘어요. b는 x = 0일 때의 높이(절편)입니다. 적외선 센서처럼 ‘전압이 0.5 V 오를 때 거리가 20 cm 준다’ 같은 관계를 실험으로 재서 a와 b를 맞추는 일을 보정이라고 해요.

아는 모양 f(x)를 바꾸는 손잡이는 넷입니다. f(x − c)는 그래프를 오른쪽으로 c만큼, f(x) + d는 위로 d만큼 옮겨요. f(bx)는 가로로 1/b배 좁히고, a·f(x)는 세로로 a배 늘입니다. 확률과 통계 101의 정규분포 식은 종 모양 e−x²/2를 μ만큼 옮기고 σ배 넓힌 것이에요. 식에 보이는 (x − μ)/σ가 바로 ‘옮기고 늘이기’입니다.

함수의 출력을 다른 함수의 입력으로 넣는 것이 합성입니다. 명령 → 모터 → 바퀴 → 위치처럼 로봇의 계산은 대부분 상자를 이어 붙인 사슬이에요. 6단계의 연쇄 법칙이 이 사슬의 변화율을 다룹니다.

def f(x):                       # 기본 모양: 종
    return np.exp(-x**2 / 2)

def transform(f, a=1.0, b=1.0, c=0.0, d=0.0):
    return lambda x: a * f(b * (x - c)) + d

mu, sigma = 1.0, 0.5            # 정규분포 = 종을 옮기고 늘인 것
g = transform(f, a=1/(sigma*np.sqrt(2*np.pi)), b=1/sigma, c=mu)

def saturate(u, umax=1.0):      # 모터 포화: 명령이 커도 출력은 umax까지

강화학습의 리턴이 바로 이런 합입니다. 지금 보상은 그대로, 한 걸음 뒤 보상은 γ배, 두 걸음 뒤는 γ²배로 깎아서 끝까지 더해요. 매 걸음 1점씩 받으면 γ = 0.9일 때 합은 10에 다가갑니다. 그래서 1/(1 − γ)를 ‘로봇이 대략 몇 걸음 앞을 보나’로 읽어요.

PID 실습의 D 필터나 확률과 통계 101의 지수 이동 평균도 같은 모양입니다. 새 값에 α, 한 칸 전 값에 α(1 − α), 두 칸 전에 α(1 − α)²… 무게를 줘서 더하면, 무게의 합은 1이고 오래된 값일수록 희미해져요.

한 줄로Σ는 ‘모두 더하라’는 기호이고, 같은 비율로 줄어드는 수를 끝없이 더하면 1/(1 − r)이라는 유한한 값에 다가갑니다. 이 ‘다가가는 값’이 극한이고, 다음 단계 미분의 정의에 그대로 쓰여요.

Σk=0n−1 ak는 k를 0부터 n − 1까지 바꿔 가며 ak를 모두 더하라는 뜻입니다. 파이썬의 sum(a[k] for k in range(n))과 똑같아요. 아래첨자 k는 반복문의 변수일 뿐이라 다른 글자로 바꿔도 뜻이 같습니다.

같은 비율 r로 곱해 나가는 수 1, r, r², …를 n개 더한 S는 (1 − rⁿ)/(1 − r)이에요. S에 r을 곱한 rS를 빼면 가운데가 모두 지워지고 1 − rⁿ만 남기 때문입니다. |r| < 1이면 n이 커질수록 rⁿ이 0으로 가니 합은 1/(1 − r)에 수렴하고, |r| ≥ 1이면 끝없이 커지거나 출렁여 발산해요.

x에서 h만큼 옮겼을 때 y의 변화를 h로 나눈 Δy/Δx는 평균 변화율, 두 점을 잇는 할선의 기울기입니다. h를 0으로 보낸 극한이 순간 변화율 f′(x)이고, 이것을 x마다 계산해 함수로 본 것이 도함수예요. 같은 것을 dy/dx로도 쓰고, 시간에 대한 미분은 위에 점을 찍어 ẋ로 씁니다. 운동 모델의 ẋ = f(x, u)는 ‘상태가 변하는 빠르기’라는 뜻이었어요.

f(x) = x²을 직접 해 보면 ((x + h)² − x²)/h = 2x + h이고, h → 0이면 2x입니다. x = 3에서 기울기가 6이에요. 위치를 미분하면 속도, 속도를 미분하면 가속도, 또 미분하면 저크, 한 번 더 하면 스냅입니다. PID 다음의 드론 제어에서 궤적을 스냅까지 매끄럽게 짠 이유가 여기 있었어요. 스냅이 모터 추력 차이에 비례하니까요.

컴퓨터는 극한 대신 작은 h로 차분을 계산합니다. 앞쪽 차분 (f(x + h) − f(x))/h의 오차는 h에 비례하고, 양쪽에서 재는 중심 차분 (f(x + h) − f(x − h))/2h는 h²에 비례해 훨씬 정확해요. 하지만 h를 1e-8보다 작게 하면 컴퓨터의 반올림 오차를 h로 나누게 되어 다시 나빠집니다. 측정값이라면 잡음이 같은 일을 훨씬 크게 일으켜요.

평균 변화율에서 순간 변화율로
(9)
  1. 1평균 변화율. 두 점을 잇는 할선의 기울기. 위치라면 h초 동안의 평균 속도예요.
  2. 2순간 변화율. h를 0으로 보낸 극한. 접선의 기울기이고, f′, dy/dx, ẋ는 모두 같은 뜻입니다.
컴퓨터의 미분: 차분
(10)
  1. 1중심 차분. 오차가 h²에 비례해 앞쪽 차분보다 훨씬 정확해요. 수치 야코비안을 구할 때도 씁니다.
  2. 2측정값의 미분. 위치 잡음 σx 두 개가 섞여 √2배, 그걸 Δt로 나누니 Δt가 작을수록 속도 잡음이 커집니다. PID의 D항과 D 필터 이야기예요.
파이썬
import numpy as np

f = lambda x: x**2
x0 = 3.0
for h in [1.0, 0.1, 0.01, 1e-6]:
    fwd = (f(x0 + h) - f(x0)) / h            # 6 + h → 6에 다가감
    cen = (f(x0 + h) - f(x0 - h)) / (2 * h)  # x²에서는 정확히 6
    print(h, fwd, cen)

dt, sigma = 0.01, 0.001                      # 100 Hz, 위치 잡음 1 mm
t = np.arange(0, 2, dt)
x_true = 0.5 * t**2                          # 가속도 1 m/s^2
x_meas = x_true + np.random.normal(0, sigma, t.size)
v_est = np.diff(x_meas) / dt                 # 속도 = 위치의 차분
v_true = t[1:] - dt / 2                      # 칸 가운데의 참 속도
print(np.std(v_est - v_true), np.sqrt(2) * sigma / dt)   # 둘 다 약 0.14

해 볼 것

  • h를 1에서 0.01까지 줄여 보세요. 빨간 할선이 주황 접선에 달라붙고, 오른쪽 ‘할선 기울기’가 ‘접선 기울기’에 다가갑니다.
  • [sin x]를 고르고 아래 오차 그래프를 보세요. h를 줄이면 오차가 줄다가, 1e-8보다 작아지면 앞쪽 차분(빨강)과 중심 차분(주황) 모두 다시 커집니다. 반올림 오차를 아주 작은 h로 나눈 탓이에요. 가장 좋은 h는 앞쪽이 1e-8, 중심이 1e-5 근처입니다. x²에서는 중심 차분의 어림 오차가 0이라 반올림 오차만 보여요.
  • [엔코더로 속도 재기]에서 측정 주기 Δt를 줄여 보세요. 위치는 더 촘촘해지는데 속도 추정(빨강)은 오히려 더 거칠어집니다. 잡음 σ를 0으로 두면 깨끗해져요. D항에 저역 필터를 다는 이유입니다.

핵심

공식 몇 개와 사슬 하나: 미분 규칙과 연쇄 법칙

쓰인 곳선형대수 101의 야코비안RL101·모방학습의 신경망 학습로봇팔 IK운동 모델
먼저, 수식 없이

매번 극한을 계산할 필요는 없습니다. 자주 나오는 함수의 기울기는 공식으로 정리돼 있어요. x²의 기울기는 2x, x³은 3x², sin x는 cos x, eˣ는 eˣ 자신. 이 몇 개와 ‘더한 것의 기울기는 기울기를 더한 것’만 알면 로봇에 나오는 식 대부분을 미분할 수 있습니다.

더 중요한 건 연쇄 법칙이에요. 자전거 페달을 1바퀴 돌리면 뒷바퀴가 3바퀴 돌고, 뒷바퀴 1바퀴에 2 m 간다면, 페달 1바퀴에 6 m 갑니다. 이어진 단계의 비율은 곱하면 돼요. 로봇팔에서 ‘모터가 도는 빠르기 → 관절 각도 → 손끝 높이’도 마찬가지로, 단계마다의 비율을 곱하면 손끝이 움직이는 빠르기가 나옵니다.

신경망 학습의 역전파가 바로 이 곱셈입니다. 입력에서 손실까지 이어진 수많은 상자의 ‘국소 기울기’를 거꾸로 곱해 나가며, 가중치 하나하나를 조금 바꾸면 손실이 얼마나 바뀌는지 한 번에 계산해요. RL101과 모방학습 실습의 신경망이 이렇게 배웠습니다.

한 줄로미분 공식 몇 개와 연쇄 법칙(이어진 단계의 기울기는 곱한다)이면 로봇 식 대부분이 미분됩니다. 역전파는 연쇄 법칙을 출력 쪽부터 차례로 적용한 것이에요.

미분 공식
자주 쓰는 함수의 도함수 목록.

까먹었다면x³ = x · x · x. 그래서 x = 2에서 x³ = 8이고, 공식 3x²으로 기울기는 12예요. x가 2에서 2.01로 가면 x³은 약 8.12로, 0.01의 12배쯤 늘어납니다.

조금 더 정확하게

거듭제곱 xⁿ의 기울기는 nxⁿ⁻¹입니다. 상수 배와 합은 그대로 따라가서 (3x² + 2x)′ = 6x + 2예요. sin의 기울기는 cos, cos의 기울기는 −sin입니다. 3단계의 도는 점으로 보면 당연해요. 높이(sin)가 가장 빨리 변하는 때는 점이 옆을 지날 때, 곧 가로 위치(cos)가 가장 클 때니까요. eˣ는 기울기가 자기 자신이라 ‘자기 크기에 비례해 변하는 양’의 답이 됩니다.

연쇄 법칙은 y가 θ를 거쳐 t에 달려 있을 때 dy/dt = (dy/dθ)(dθ/dt)라는 것입니다. 길이 L인 팔이 각속도 θ̇로 돌면 손끝 높이 y = L sin θ의 변화는 L cos θ · θ̇예요. 팔이 수평(θ = 0)일 때는 cos θ = 1이라 손끝이 가장 빨리 오르고, 수직(θ = 90°)일 때는 0이라 위로는 거의 안 움직입니다.

입력과 출력이 여러 개면 이 비율들을 표로 늘어놓게 되고, 그것이 선형대수 101 7단계의 야코비안입니다. 관절 각속도에 야코비안을 곱하면 손끝 속도가 나오죠. 사슬이 길어도 원리는 같아요. 단계마다의 비율(행렬)을 차례로 곱합니다. PyTorch 같은 프레임워크의 자동 미분은 이 곱을 대신 계산해 주는 도구예요.

외워 둘 미분
(11)
  1. 1거듭제곱. 지수가 앞으로 내려오고 하나 줄어요. (x²)′ = 2x, (x)′ = 1, 상수의 기울기는 0.
  2. 2삼각함수. 라디안일 때만 이렇게 깔끔합니다. 도 단위면 π/180이 따라붙어요.
  3. 3지수와 로그. eˣ는 미분해도 자기 자신. ln x의 기울기는 1/x.
  4. 4합과 상수 배는 그대로. 조각마다 미분해서 더하면 됩니다.
연쇄 법칙
(12)
  1. 1사슬의 비율은 곱한다. θ가 1 rad 변할 때 y가 dy/dθ만큼, 1초에 θ가 dθ/dt만큼 변하니까요.
  2. 2로봇팔 한 마디. 손끝 높이의 변화 = (각도에 대한 높이의 비율 L cos θ) × (모터 각속도 θ̇). 관절이 여럿이면 이 비율들이 야코비안이 됩니다.
파이썬
import numpy as np

L, theta, omega = 0.5, np.deg2rad(30), 2.0   # 팔 길이, 각도, 각속도(rad/s)
dy_dtheta = L * np.cos(theta)                # 국소 기울기 1: 0.433
dtheta_dt = omega                            # 국소 기울기 2: 2.0
dy_dt = dy_dtheta * dtheta_dt                # 연쇄 법칙: 0.866 m/s

# 역전파: loss = (w*x - t)^2 의 w에 대한 기울기
x, t, w = 2.0, 3.0, 0.5
u = w * x                       # 앞으로: 1.0
e = u - t                       #        -2.0
loss = e**2                     #         4.0
dL_de = 2 * e                   # 뒤로:  -4.0
de_du = 1.0
du_dw = x                       #         2.0
dL_dw = dL_de * de_du * du_dw   # -8.0 → w를 키우면 손실이 준다
w -= 0.05 * dL_dw               # 경사 하강 한 걸음 (7단계): w = 0.9

해 볼 것

  • 모터 각속도를 2배로 올리면 세 칸 중 dθ/dt와 결과 dy/dt만 2배가 되고 dy/dθ는 그대로입니다. 단계마다의 비율이 따로 정해지고 곱으로 이어지기 때문이에요.
  • [역전파 한 걸음]에서 [한 걸음]을 몇 번 눌러 보세요. 기울기 dL/dw가 음수면 w가 커지고, 손실이 0에 다가가면서 기울기도 0으로 줄어듭니다. 학습률을 0.2로 올리면 좌우로 건너뛰며 다가가고, 0.3이면 튕겨 나가요. 이 손실의 곡률이 2x² = 8이라 η × 8이 2를 넘으면 발산합니다(7단계).

기울기가 0인 바닥: 최솟값과 경사 하강

쓰인 곳RL101·모방학습의 신경망 학습포즈 그래프 SLAM선형대수 101의 최소제곱확률과 통계 101의 평균과 중앙값
먼저, 수식 없이

안개 낀 산에서 골짜기 바닥으로 내려가야 한다고 해 봅시다. 앞이 안 보여도 발밑이 어느 쪽으로 기울었는지는 느낄 수 있어요. 내리막 쪽으로 한 걸음, 또 한 걸음. 바닥에 닿으면 어느 쪽도 기울지 않습니다. 기울기가 0인 곳이 바닥이에요.

로봇 공학의 ‘가장 좋은 것 찾기’는 대부분 이렇게 풉니다. SLAM은 측정과 지도가 어긋난 정도(오차 제곱합)가 가장 작은 지도를, 신경망은 손실이 가장 작은 가중치를 찾아요. 기울기를 보고 내리막으로 조금씩 가는 방법이 경사 하강법입니다.

보폭이 문제예요. 너무 작으면 바닥까지 한참 걸리고, 너무 크면 골짜기를 건너뛰어 반대편 벽을 오가다 결국 튕겨 나갑니다. 신경망의 학습률을 고르는 고민이 바로 이것이에요. 또 골짜기가 여러 개면 처음 선 자리에 따라 가까운 바닥에 갇힐 수 있습니다.

한 줄로최솟값에서는 기울기가 0입니다. 경사 하강법은 ‘기울기의 반대쪽으로 η만큼’을 되풀이해 바닥을 찾고, η가 너무 크면 발산해요.

조금 더 정확하게

매끄러운 함수가 가장 작아지는 x*에서는 f′(x*) = 0입니다. 기울기가 음수면 오른쪽으로 가서 더 줄일 수 있고, 양수면 왼쪽으로 가면 되니까요. 하지만 기울기 0이 꼭 바닥은 아니에요. 꼭대기나 잠깐 평평한 곳일 수도 있습니다. 기울기의 기울기인 2차 미분 f″가 양수면(아래로 볼록, 그릇 모양) 바닥이에요.

식을 풀어 f′ = 0을 바로 구할 수 있으면 좋겠지만, 신경망처럼 변수가 수백만 개면 불가능합니다. 그래서 xk+1 = xk − ηf′(xk)를 되풀이해요. 그릇 f = (a/2)(x − 1)²에서는 한 걸음마다 바닥까지 거리가 (1 − ηa)배가 되니, ηa가 0~1이면 한쪽에서, 1~2면 건너뛰며 다가가고, 2를 넘으면 발산합니다. 12단계의 오일러 방법, PID 실습의 KαΔt와 같은 조건이에요.

익숙한 예가 하나 있습니다. 데이터 x₁, …, xₙ을 숫자 하나 c로 대표할 때 오차 제곱합 Σ(xᵢ − c)²를 가장 작게 하는 c는? 미분해서 0으로 놓으면 c = 평균이 나와요. 오차의 절댓값 합을 최소로 하면 중앙값이 됩니다. 확률과 통계 101에서 ‘이상치에는 중앙값’이라고 한 이유가 여기 있어요. 선형대수 101의 최소제곱과 SLAM은 이 이야기를 벡터로 넓힌 것입니다.

언덕의 가장 가파른 방향: 편미분과 그래디언트

쓰인 곳경로 계획(퍼텐셜 필드)선형대수 101의 야코비안과 IK포즈 그래프 SLAM의 가우스-뉴턴신경망 학습
먼저, 수식 없이

등산 지도의 등고선을 떠올려 보세요. 같은 높이를 이은 선이 촘촘한 곳은 가파르고, 성긴 곳은 완만합니다. 어느 자리에 서든 ‘가장 가파르게 오르는 방향’이 하나 있는데, 그 방향은 늘 등고선과 직각이에요. 이 방향과 가파른 정도를 함께 담은 화살표가 그래디언트입니다.

변수가 둘이면 기울기도 방향마다 다릅니다. 동쪽으로만 한 걸음 갔을 때의 기울기, 북쪽으로만 갔을 때의 기울기를 따로 재는 것이 편미분이에요. 이 둘을 묶은 벡터가 그래디언트고요.

로봇 경로 계획에는 지도 전체를 언덕으로 만드는 방법이 있습니다. 목표는 깊은 골짜기, 장애물은 높은 봉우리로 놓고, 로봇은 그래디언트의 반대쪽(가장 가파른 내리막)으로 굴러가요. 이것이 퍼텐셜 필드 방법입니다. 계산이 아주 싸지만 7단계의 국소 최솟값 함정이 그대로 있어요.

한 줄로편미분은 한 변수만 움직였을 때의 기울기, 그래디언트는 그걸 모은 화살표입니다. 가장 가파른 오르막을 가리키고 등고선과 직각이에요. 반대로 가면 가장 빨리 내려갑니다.

까먹었다면f(x, y) = x² + 3y라면 y를 숫자 취급하고 x로 미분해 ∂f/∂x = 2x, x를 숫자 취급하고 y로 미분해 ∂f/∂y = 3이에요.

f(x, y)의 편미분 ∂f/∂x는 y를 고정한 채 x만 h 움직인 변화율입니다. 둥근 d 대신 ∂(파셜)을 써서 ‘다른 변수는 그대로’임을 표시해요. 계산은 다른 변수를 숫자 취급하고 평소처럼 미분하면 됩니다.

두 편미분을 세로로 쌓은 ∇f가 그래디언트예요. 아무 방향 u(길이 1)로 한 걸음 갔을 때의 기울기는 내적 ∇f · u이고, 선형대수 101 2단계에서 봤듯 내적은 u가 ∇f와 같은 방향일 때 가장 큽니다. 그래서 ∇f는 가장 가파른 오르막을 가리키고, 그 길이가 가파른 정도예요. 등고선을 따라가면 높이가 안 변하니(기울기 0) 등고선은 ∇f와 직각입니다.

출력이 여러 개인 함수(손끝의 x와 y처럼)라면 출력마다 그래디언트가 하나씩 있고, 이것을 행으로 쌓은 표가 야코비안 J입니다. 선형대수 101의 IK가 J⊤e 방향으로 관절을 고친 것은 ‘오차 제곱의 그래디언트 반대쪽으로 한 걸음’이었어요. SLAM의 가우스-뉴턴도 이 그래디언트(b)와 곡률(H)로 걸음을 정했습니다.

파이썬
import numpy as np

def U(p, goal, obs, ka=1.0, kr=1.0, rho0=1.5):
    u = 0.5 * ka * np.sum((p - goal)**2)          # 끌림
    for c, r in obs:                              # (중심, 반지름)
        d = np.linalg.norm(p - c) - r
        if d < rho0:
            u += 0.5 * kr * (1/d - 1/rho0)**2     # 밀침
    return u

def grad(f, p, h=1e-5):                           # 수치 그래디언트
    g = np.zeros(2)
    for i in range(2):
        e = np.zeros(2); e[i] = h
        g[i] = (f(p + e) - f(p - e)) / (2 * h)    # 편미분 = 중심 차분
    return g

p, goal = np.array([1.0, 1.0]), np.array([8.0, 5.0])
obs = [(np.array([4.0, 3.5]), 0.8)]
for k in range(300):
    g = grad(lambda q: U(q, goal, obs), p)
    p = p - 0.05 * g / (np.linalg.norm(g) + 1e-9)  # 내리막으로 한 걸음

곡선을 가까이서 보면 직선: 테일러 전개와 선형화

쓰인 곳베이즈 필터의 EKFPID 다음의 드론 제어(작은 각 선형화)포즈 그래프 SLAM의 가우스-뉴턴선형대수 101의 행렬 지수
먼저, 수식 없이

지구는 둥글지만 운동장은 평평해 보입니다. 아주 큰 곡선도 가까이서 보면 거의 직선이에요. 지금 자리의 높이와 기울기만 알면, 근처는 직선으로 꽤 정확히 짐작할 수 있습니다. 더 정확히 하려면 휘는 정도(2차 미분)까지 써서 포물선으로 맞추면 되고요. 이렇게 함수를 지금 자리 근처의 다항식으로 바꾸는 것이 테일러 전개입니다.

로봇 공학의 많은 방법이 ‘직선으로 펴기’에 기대요. 드론 제어는 기울기가 작을 때 sin θ ≈ θ, cos θ ≈ 1로 펴서 행렬 계산으로 바꿨고, EKF는 비선형 운동·센서 모델을 지금 추정값에서 접선으로 펴서 칼만 필터를 썼어요. SLAM의 가우스-뉴턴은 ‘펴고, 풀고, 옮기고, 다시 펴기’를 되풀이했고요.

대신 직선 근사는 지금 자리에서 멀어질수록 틀립니다. sin θ ≈ θ는 10°에서 0.5%만 틀리지만 45°에서는 11% 틀려요. EKF가 ‘지금 추정이 대체로 맞다’는 전제에서만 잘 동작한 이유입니다.

한 줄로테일러 전개는 함수를 한 점 근처의 다항식으로 바꿉니다. 1차까지만 쓰면 선형화이고, 그 점에서 멀어질수록 오차가 커져요.

import numpy as np
from math import factorial

def taylor_sin(x, a=0.0, order=3):
    s = 0.0
    for k in range(order + 1):
        dk = np.sin(a + k * np.pi / 2)       # sin의 k번 미분, a에서
        s += dk / factorial(k) * (x - a)**k
    return s

쓰인 곳운동 모델의 적분PID의 I항추측 항법(오도메트리)3D 드론의 자세 갱신
먼저, 수식 없이

택시 미터기는 매 순간의 속도를 알면 탄 거리를 압니다. 1초마다 ‘지금 속도 × 1초’를 더해 가면 되니까요. 초속 10 m로 3초, 초속 5 m로 2초 갔다면 30 + 10 = 40 m. 속도 그래프로 보면 이 계산은 막대 넓이를 더한 것이에요. 이렇게 잘게 나눠 쌓는 것이 적분입니다.

속도가 계속 바뀌면 막대를 더 가늘게 자르면 됩니다. 0.1초, 0.01초… 가늘수록 막대들의 윗면이 곡선에 붙고, 넓이의 합은 곡선 아래 넓이에 다가가요. 그 극한이 정적분 ∫입니다. ∫는 합(Sum)의 S를 길게 늘인 글자예요.

로봇이 바퀴 회전수로 위치를 짐작하는 추측 항법(오도메트리), PID의 I항(지금까지 쌓인 오차), 시뮬레이터가 속도로 위치를 갱신하는 것까지 모두 이 쌓기입니다. 대신 막대 하나하나의 작은 오차도 같이 쌓여서, 오래 쌓으면 위치가 점점 틀어져요.

한 줄로적분은 ‘속도 × 짧은 시간’을 모두 더하는 것, 그래프에서는 곡선 아래 넓이입니다. 막대를 가늘게 할수록 정확해지고, 그 극한이 ∫예요.

조금 더 정확하게

구간 [0, T]를 n칸으로 나누면 한 칸의 폭은 Δt = T/n이고, 칸마다 v(tᵢ)Δt를 더한 Σv(tᵢ)Δt가 리만 합이에요. n → ∞의 극한이 정적분 ∫₀T v(t) dt입니다. dt는 ‘한없이 가는 막대의 폭’이고, Σ가 ∫로, Δt가 dt로 바뀐 것뿐이에요. 속도가 음수(후진)인 구간은 넓이도 음수로 세서 빼집니다. 그래서 적분값은 ‘움직인 거리’가 아니라 ‘출발점에서 떨어진 정도(변위)’예요.

막대의 높이를 어디서 재느냐에 따라 정확도가 다릅니다. 칸의 왼쪽 끝 높이를 쓰면(왼쪽 합) 오차가 Δt에 비례하고, 가운데 높이나 양 끝의 평균(사다리꼴)을 쓰면 Δt²에 비례해요. 5단계의 앞쪽 차분과 중심 차분과 같은 이야기입니다. 엔코더 오도메트리에서 ‘지난 속도와 지금 속도의 평균’을 쓰는 것이 사다리꼴 공식이에요.

프로그램에서는 극한 대신 xk+1 = xk + vkΔt를 반복합니다. 운동 모델 실습의 오일러 방법, PID 코드의 self.integral += e * dt가 모두 이 한 줄이에요. 3D 드론 실습에서는 자세를 더하는 대신 작은 회전을 곱해 쌓았는데, 쌓는 대상이 회전이라 ‘더하기’가 ‘곱하기’로 바뀐 것일 뿐 생각은 같습니다.

리만 합과 정적분
(19)

  2. 2정적분. 막대를 한없이 가늘게 한 극한, 곡선 아래 넓이. 아래 끝 0과 위 끝 T가 구간이에요.
컴퓨터의 적분: 한 칸씩 더하기
(20)
  1. 1왼쪽 합 = 오일러. 칸이 시작할 때의 속도로 한 칸 전체를 갑니다. 운동 모델의 step_euler, PID의 integral이 이 꼴이에요.
  2. 2사다리꼴. 칸 양 끝 속도의 평균을 씁니다. 같은 Δt에서 오차가 훨씬 작아요.
파이썬
import numpy as np

def v(t):                                   # 속도 (m/s): 가속-등속-감속
    return 0.5 * np.clip(t, 0, 2) - 0.5 * np.clip(t - 7, 0, 2)

T, n = 10.0, 20
dt = T / n
t = np.arange(n) * dt
left = np.sum(v(t) * dt)                    # 왼쪽 리만 합
mid  = np.sum(v(t + dt / 2) * dt)           # 가운데
trap = np.sum((v(t) + v(t + dt)) / 2 * dt)  # 사다리꼴

x = 0.0                                     # 오도메트리: 한 칸씩 쌓기
for k in range(n):
    x += (v(t[k]) + v(t[k] + dt)) / 2 * dt
print(left, mid, trap, x)                   # 정확한 값은 7.0

미분과 적분은 서로를 되돌린다: 기본 정리와 확률 밀도

쓰인 곳확률과 통계 101의 정규분포베이즈 필터PID의 I항과 D항
먼저, 수식 없이

통장 잔고와 매일의 입출금을 생각해 봅시다. 입출금을 날마다 쌓으면 잔고가 되고(적분), 잔고가 하루에 얼마나 변했는지 보면 그날의 입출금이 나와요(미분). 쌓은 것의 변화율은 원래 쌓던 것입니다. 이것이 미적분의 기본 정리예요.

덕분에 넓이를 막대 없이 계산할 수 있습니다. 미분해서 f가 되는 함수 F를 하나 찾으면, a에서 b까지의 넓이는 F(b) − F(a) 뺄셈 한 번이에요. x²를 0부터 1까지 쌓은 넓이는, x³/3을 미분하면 x²이니까 1/3 − 0 = 1/3입니다.

확률 밀도도 이 틀로 읽습니다. 로봇 위치가 ‘정확히 3.000… m일 확률’은 0이에요. 의미 있는 건 ‘2.9~3.1 m 사이일 확률’이고, 이것이 밀도 곡선 아래의 넓이입니다. 전체 넓이는 1. 정규분포의 ‘±1σ 안에 68%’는 이 넓이를 잰 값이었어요.

한 줄로쌓은 함수 F를 미분하면 원래 함수 f가 나옵니다. 그래서 넓이는 F(b) − F(a)로 계산하고, 확률 밀도에서는 넓이가 확률입니다.

기본 정리
쌓은 것의 기울기는 원래 높이. 적분과 미분은 서로 거꾸로.
원시함수 F
미분해서 f가 되는 함수. 부정적분이라고도 해요.
확률 밀도 p(x)
넓이가 확률인 곡선. 높이는 1을 넘을 수 있어요.

X가 x보다 작을 확률. 밀도를 −∞부터 쌓은 것.

조금 더 정확하게

F(x) = ∫ₐˣ f(s) ds를 ‘a부터 x까지 쌓은 넓이’로 정의하면, x를 h 늘릴 때 늘어나는 넓이는 대략 폭 h, 높이 f(x)인 막대 하나입니다. 그래서 (F(x + h) − F(x))/h → f(x), 곧 F′ = f예요. 쌓기(적분)와 기울기(미분)가 서로를 되돌립니다. PID의 I항은 오차를 쌓고 D항은 오차의 기울기를 보니, 둘은 같은 신호에 대한 반대 방향의 연산이에요.

미분해서 f가 되는 F를 f의 원시함수(부정적분)라고 하고, 6단계의 공식을 거꾸로 읽으면 얻습니다. xⁿ의 원시함수는 xⁿ⁺¹/(n + 1), cos은 sin, eˣ는 eˣ예요. 그러면 ∫ₐᵇ f dx = F(b) − F(a)입니다. 원시함수를 식으로 못 구하는 함수도 많은데, 정규분포가 대표적이에요. 그래서 누적 분포는 미리 계산된 근사식이나 scipy.stats.norm.cdf로 구합니다.

연속 확률 변수 X의 확률 밀도 p(x)는 넓이가 확률인 곡선입니다. P(a < X < b) = ∫ₐᵇ p(x) dx이고 전체 넓이는 1이에요. 높이 자체는 확률이 아니라 ‘1 m당 확률’이라서 1보다 클 수도 있습니다(σ가 작으면 종이 뾰족하고 높아요). 넓이를 −∞부터 쌓은 F(x) = P(X < x)가 누적 분포 함수이고, 기본 정리에 따라 그 기울기가 밀도입니다.

미적분의 기본 정리

  2. 2쌓은 것의 기울기는 원래 높이. x를 h 늘리면 넓이는 막대 하나 f(x)·h만큼 늘어나니까요.
  3. 3넓이는 뺄셈 한 번. 미분해서 f가 되는 F를 찾으면 막대를 쌓을 필요가 없습니다.

  3. 3정규분포의 밀도. 1단계의 종 모양을 μ만큼 옮기고 σ배 넓힌 뒤, 넓이가 1이 되게 1/(σ√2π)를 곱했어요.
파이썬
import numpy as np
from scipy.stats import norm

F = lambda x: x**3 / 3             # x^2의 원시함수
print(F(1) - F(0))                 # 0.3333 = x^2을 0부터 1까지 쌓은 넓이

mu, sigma = 3.0, 0.2               # 로봇 위치 추정 (m)
a, b = 2.9, 3.1
p_ab = norm.cdf(b, mu, sigma) - norm.cdf(a, mu, sigma)
print(p_ab)                        # 0.383 = 넓이 = 확률

xs = np.linspace(a, b, 1001)       # 같은 넓이를 막대로 쌓아도
dx = xs[1] - xs[0]
print(np.sum(norm.pdf(xs[:-1] + dx/2, mu, sigma)) * dx)   # 0.383
print(norm.pdf(mu, mu, sigma))     # 1.995  ← 높이는 1을 넘을 수 있다

변화의 규칙으로 미래를 계산한다: 미분방정식과 시뮬레이션

쓰인 곳운동 모델 1장의 적분 방법MuJoCo 시뮬레이터PID 실습의 카트3D 드론의 자세 갱신
먼저, 수식 없이

‘뜨거운 커피는 주변보다 뜨거운 만큼 빨리 식는다’는 규칙만 알아도 10분 뒤 온도를 계산할 수 있습니다. 지금 온도에서 1초 동안 식는 양을 빼고, 새 온도에서 다시 1초… 이렇게 변화의 규칙(미분)으로 미래를 한 칸씩 쌓아 가는(적분) 것이 시뮬레이션이에요. 변화율로 적은 규칙을 미분방정식이라고 합니다.

MuJoCo도, 운동 모델 실습도, PID의 카트도 같은 일을 합니다. ‘지금 상태와 힘을 넣으면 변화율이 나오는’ 함수 f를 만들고, 작은 시간 Δt마다 상태에 ‘f × Δt’를 더해요. 이 간단한 방법이 오일러 방법입니다.

Δt를 너무 크게 잡으면 큰일이 납니다. 한 칸 동안 변화율이 그대로라고 가정하는데, 그 사이에 상황이 크게 바뀌면 지나쳐 버려요. 커피 온도가 실온보다 내려가거나, 용수철이 점점 크게 출렁이다 터져 버리죠. 그래서 Δt를 작게 하거나, 순서를 바꾼 반암시적 오일러나 한 칸 안을 네 번 살펴보는 RK4를 씁니다.

한 줄로미분방정식은 변화율의 규칙이고, 시뮬레이터는 그 규칙으로 상태를 Δt씩 쌓아 갑니다. Δt가 크면 오일러 방법은 지나치거나 발산해요.

미분방정식
변화율과 상태의 관계를 적은 식. ẋ = f(x).
오일러 방법
한 칸 동안 변화율이 그대로라고 보고 더하기.
반암시적 오일러
속도를 먼저 고치고 새 속도로 위치를 옮기기.
RK4
한 칸 안의 기울기 넷을 평균 내는 정확한 방법.

까먹었다면x₀ = 100에서 매 칸 10%씩 줄면 x₁ = 90, x₂ = 81, x₃ = 72.9예요. 매 칸 0.9를 곱하니 xₙ = 100 × 0.9ⁿ입니다(2단계의 지수).

조금 더 정확하게

가장 간단한 미분방정식 ẋ = −kx는 ‘자기 크기에 비례해 줄어든다’입니다. eˣ의 기울기가 자기 자신이었으니(6단계), 답은 x(t) = x₀e−kt예요. 오일러 방법은 한 칸마다 x에 (1 − kΔt)를 곱합니다. kΔt가 1보다 작으면 제대로 줄어들고, 1~2면 부호를 바꿔 가며 지나치면서 줄어들고, 2를 넘으면 지나치는 폭이 커져 발산해요. 7단계의 경사 하강, PID 실습의 KαΔt와 같은 조건입니다.

용수철-댐퍼 ẍ = −kx − cẋ는 미분이 두 번이라, 속도 v를 상태에 넣어 ẋ = v, v̇ = −kx − cv 두 개의 1차 식으로 바꿉니다. 운동 모델 실습에서 봤듯, 오일러는 지난 속도로 위치를 옮겨 에너지가 조금씩 늘고, 반암시적 오일러는 속도를 먼저 갱신하고 새 속도로 위치를 옮겨 에너지가 거의 보존돼요. MuJoCo의 기본 적분기가 이 계열입니다.

RK4(4차 룽게-쿠타)는 한 칸 안에서 처음, 가운데 두 번, 끝의 변화율을 계산해 가중 평균을 냅니다. 오차가 Δt⁴에 비례해서, Δt를 절반으로 하면 오차가 16분의 1이 돼요. 한 칸에 f를 네 번 계산하는 대신 큰 Δt를 쓸 수 있습니다. 실제 시뮬레이터는 정확도, 속도, 에너지 보존 사이에서 고릅니다.

변화율 규칙과 지수 감쇠
(23)
  1. 1변화율의 규칙. 지금 크기에 비례해 줄어듭니다. k가 클수록 빨리.
  2. 2정확한 답. 미분하면 −k × 자기 자신이니 규칙을 만족해요. 반감기는 ln 2 / k.
  3. 3오일러 한 칸. 매 칸 (1 − kΔt)배. |1 − kΔt| > 1, 곧 kΔt > 2면 발산합니다.
용수철-댐퍼와 적분기
(24)
  1. 1용수철-댐퍼. 질량 1에 용수철 k, 댐퍼 c. PD 제어기를 단 카트와 같은 꼴이에요(PID 실습).
  2. 2반암시적 오일러. 속도를 먼저, 새 속도로 위치를. 그냥 오일러는 둘째 식에 vk를 씁니다.
  3. 3RK4. 상태 s = (x, v). 한 칸 안의 기울기 넷(처음, 가운데 둘, 끝)을 1:2:2:1로 평균. 오차가 Δt⁴에 비례해요.
파이썬
import numpy as np

k, c, dt = 4.0, 0.3, 0.1
acc = lambda x, v: -k * x - c * v

def euler(x, v):
    return x + dt * v, v + dt * acc(x, v)

def semi_implicit(x, v):                  # MuJoCo 기본 적분기 계열
    v = v + dt * acc(x, v)
    return x + dt * v, v

def rk4(x, v):
    f = lambda s: np.array([s[1], acc(s[0], s[1])])
    s = np.array([x, v])
    k1 = f(s); k2 = f(s + dt/2 * k1); k3 = f(s + dt/2 * k2); k4 = f(s + dt * k3)
    return tuple(s + dt/6 * (k1 + 2*k2 + 2*k3 + k4))

for step in (euler, semi_implicit, rk4):
    x, v = 1.0, 0.0
    for _ in range(200):                  # 20초
        x, v = step(x, v)
    print(step.__name__, x, 0.5*v*v + 0.5*k*x*x)   # 위치, 에너지

해 볼 것

  • [용수철-댐퍼]에서 감쇠 c를 0으로 두고 Δt = 0.1로 돌려 보세요. 오일러(빨강)는 진폭이 점점 커지고, 반암시적(주황)은 정확한 답(청록)과 거의 같은 진폭을 유지하며, RK4(파랑)는 정확한 답에 겹쳐 보입니다. 아래 에너지 그래프가 차이를 숫자로 보여 줘요.
  • Δt를 0.4까지 키우면 RK4도 위상이 어긋나기 시작합니다. k = 4면 한 번 출렁이는 주기가 π초(약 3.1초)인데, 그 한 주기를 8칸 정도로만 나누는 셈이니까요.

핵심

미분방정식은 변화율의 규칙이고, 시뮬레이터는 Δt마다 그 규칙을 쌓아 미래를 계산합니다. 오일러는 단순하지만 Δt가 크면 발산하고, 반암시적 오일러는 에너지를, RK4는 정확도를 지켜요.

돌리는 수: 복소수와 오일러 공식

쓰인 곳선형대수 101의 회전과 안정성선형대수 101의 행렬 지수3D 드론의 쿼터니언다음 단계의 DFT
먼저, 수식 없이

수직선에서 −1을 곱하면 방향이 반대로, 곧 180° 돌아갑니다. 그럼 ‘두 번 하면 180°가 되는’ 90° 돌리기에 해당하는 수가 있을까요? 수직선 위에는 없어요. 그래서 수를 평면으로 넓히고, 90° 돌리기를 i라고 부릅니다. 두 번 돌리면 180°이니 i² = −1이에요. 이렇게 평면 위의 점으로 넓힌 수가 복소수입니다.

복소수의 진짜 쓸모는 곱하기가 돌리기라는 점이에요. 두 복소수를 곱하면 길이는 곱해지고 각도는 더해집니다. 회전 행렬로 하던 2D 회전을 숫자 곱셈 한 번으로 할 수 있어요. 3D 드론의 쿼터니언은 이 생각을 3D로 넓힌 것입니다.

그리고 수학에서 가장 유명한 식이 나옵니다. eiθ = cos θ + i sin θ. 이 오일러 공식은 ‘eiθ는 원 위에서 각도 θ인 점’이라는 뜻이에요. θ가 시간에 따라 커지면 점이 원을 돌고, 그 그림자가 3단계의 사인파입니다. 그래서 사인파를 ‘도는 화살표’로 다룰 수 있고, 이것이 다음 단계부터 나오는 푸리에 변환의 언어예요.

한 줄로복소수는 평면 위의 점이고, 곱하면 길이는 곱해지고 각도는 더해집니다. 오일러 공식 eiθ = cos θ + i sin θ는 각도 θ만큼 돈 단위 원 위의 점이에요.

복소수 z = a + bi는 평면 위의 점 (a, b)입니다. a가 실수부, b가 허수부예요. 더하기는 벡터처럼 칸끼리 하고, 곱하기는 괄호를 풀고 i² = −1을 쓰면 됩니다. 같은 점을 원점에서의 거리 r = |z|와 각도 θ = arg z로 쓰면 z = r(cos θ + i sin θ)이고, 이 꼴로 두 수를 곱하면 삼각함수의 덧셈 정리가 깔끔히 정리되어 ‘길이는 곱, 각도는 합’이 나와요. 그래서 |w| = 1인 w를 곱하는 건 순수한 회전입니다.

같은 w를 계속 곱하면 점이 일정한 각도씩 돌면서 |w|배씩 커지거나 줄어요. |w| < 1이면 안쪽으로 감기는 나선, > 1이면 바깥으로 풀리는 나선입니다. 선형대수 101 10단계에서 ‘고유값이 단위원 안에 있어야 안정’이라고 한 고유값이 바로 이런 복소수였어요. 출렁이며 줄어드는 응답이 안쪽 나선입니다.

오일러 공식은 9단계의 eˣ 급수에 x = iθ를 넣으면 나옵니다. i의 거듭제곱이 1, i, −1, −i로 돌면서 짝수 항(실수)은 cos의 급수, 홀수 항(허수)은 sin의 급수로 갈라져요. 그림으로는 항 하나하나가 앞 항에서 90° 돌고 점점 짧아지는 화살표이고, 이어 붙이면 원 위의 점에 닿습니다. 또 eiθ와 e−iθ를 더하면 허수부가 지워져 2cos θ가 돼요. 실수 사인파 하나는 반대로 도는 화살표 두 개의 합이고, DFT 결과에 ‘음의 주파수’ 짝이 생기는 이유입니다.

  2. 2극형식. 길이와 각도로 적기. 3단계의 (cos θ, sin θ)에 길이 r을 곱한 점이에요.
  3. 3곱하기 = 늘이고 돌리기. 길이는 곱하고 각도는 더합니다. 2×2 회전 행렬 곱과 같은 일을 숫자 하나로 해요.

  2. 2급수로 보면. 9단계의 eˣ 급수에 iθ를 넣은 것. 항마다 90°씩 돌며 짧아지는 화살표예요.
  3. 3사인파 = 화살표 두 개. 반대로 도는 둘을 더하면 허수부가 지워지고 실수 cos이 남습니다.

핵심

복소수는 평면 위의 점이고, 곱하기는 ‘길이는 곱, 각도는 합’인 돌리기입니다. 오일러 공식 eiθ = cos θ + i sin θ 덕분에 사인파를 도는 화살표로 다룰 수 있고, 실수 사인파는 반대로 도는 화살표 둘의 합이에요.

사인파를 쌓아 무엇이든: 푸리에 급수

쓰인 곳4족 보행의 주기 걸음새PID 실습의 S자 오차다음 단계의 DFT
먼저, 수식 없이

오케스트라가 같은 ‘라’ 음을 내도 바이올린과 플루트 소리는 다르게 들립니다. 둘 다 1초에 440번 떨지만, 그 위에 880번, 1320번 떠는 작은 떨림이 얼마나 섞였는지가 달라서예요. 주기적으로 되풀이되는 신호는 모두 기본 진동수와 그 정수배 사인파들의 합으로 쓸 수 있습니다. 이것이 푸리에 급수예요.

심지어 각진 네모파도 됩니다. 1배 사인파에 3배 사인파를 1/3만큼, 5배를 1/5만큼… 더해 갈수록 모서리가 점점 날카로워져요. 사인파마다 진동수, 크기, 위상이 있으니, 신호를 ‘어느 진동수가 얼마나’라는 막대그래프(스펙트럼)로 바꿔 볼 수 있습니다.

4족 로봇의 걸음은 주기 T로 되풀이되고, 바퀴 하나의 불균형은 회전수와 같은 진동수로 떨림을 만듭니다. 신호를 사인파로 쪼개 보면 ‘이 떨림은 모터 회전 때문이구나’처럼 원인이 보여요.

한 줄로되풀이되는 신호는 기본 진동수와 그 정수배 사인파들의 합입니다. 어떤 진동수가 얼마나 섞였는지 적은 것이 스펙트럼이에요.

주기 T인 신호 x(t)는 x(t) = a₀ + Σ(aₙ cos 2πnf₀t + bₙ sin 2πnf₀t)로 쓸 수 있습니다(f₀ = 1/T). a₀는 평균 높이, aₙ과 bₙ은 n번째 고조파의 cos, sin 성분 크기예요. 13단계의 말로 하면 n번째 고조파는 f₀의 n배 빠르기로 도는 화살표 하나이고, 신호는 이런 화살표들을 이어 붙인 끝의 그림자입니다. 실습의 ‘원 위의 원’ 그림이 그것이에요.

계수는 신호와 각 사인파의 ‘닮은 정도’로 구합니다. bₙ = (2/T)∫₀T x(t) sin(2πnf₀t) dt처럼 곱해서 한 주기 동안 쌓는 거예요(11단계의 적분). 서로 다른 진동수의 사인파끼리는 곱해서 쌓으면 0이 되어(직교), 각 계수가 자기 진동수만 골라냅니다. 다음 단계의 DFT가 이 적분을 샘플의 합으로 바꾼 것이에요.

네모파처럼 끊긴 곳이 있는 신호는 항을 아무리 늘려도 모서리 근처에서 점프 크기의 약 9%만큼 솟는 뾰족함이 남습니다(깁스 현상). 계수가 1/n로 천천히 줄어서 높은 고조파가 많이 필요하기 때문이에요. 세모파처럼 꺾이기만 한 신호는 1/n²로 빨리 줄어 몇 항만으로도 거의 맞습니다. 매끄러운 신호일수록 스펙트럼이 낮은 진동수에 모여요.

샘플 N개에서 주파수를 찾는다: 이산 푸리에 변환

쓰인 곳선형대수 101의 내적14단계의 푸리에 계수센서 신호의 진동 분석
먼저, 수식 없이

라디오 다이얼을 돌리면 특정 주파수의 방송만 크게 들립니다. 다이얼이 맞춘 주파수와 같은 빠르기로 떠는 성분에만 반응하기 때문이에요. 이산 푸리에 변환(DFT)은 이 다이얼을 0 Hz부터 끝까지 하나씩 맞춰 보며 ‘이 주파수가 얼마나 들어 있나’를 재는 계산입니다.

재는 방법은 내적이에요. 샘플 N개짜리 신호와 같은 길이의 ‘기준 사인파’를 칸끼리 곱해 더합니다. 신호에 그 주파수 성분이 있으면 곱이 계속 같은 부호로 쌓여 크게 나오고, 없으면 +와 −가 번갈아 상쇄되어 0에 가까워져요. 선형대수 101에서 본 ‘같은 방향이면 내적이 크다’와 같은 이야기입니다.

그림으로 보면 더 재미있습니다. 신호를 원 둘레에 감아요. 감는 빠르기가 신호의 주파수와 맞으면 높은 값들이 한쪽에 몰려 무게중심이 원점에서 멀어지고, 안 맞으면 고르게 퍼져 무게중심이 원점 근처에 머뭅니다. 그 무게중심이 바로 DFT 값이에요.

한 줄로DFT는 신호를 주파수마다의 기준 사인파와 내적해 ‘그 주파수가 얼마나 섞였나’를 잽니다. 결과 Xk는 복소수이고, 크기가 세기, 각도가 위상이에요.

샘플링 주파수 fs
1초에 몇 번 쟀나.
주파수 칸 k
N개 샘플 동안 k번 도는 기준 사인파. k·fs/N Hz.
크기 스펙트럼 |Xk|
칸마다 성분의 세기.
누설과 창 함수
칸 사이 주파수가 이웃 칸으로 번지는 것과 그걸 줄이는 곱.

까먹었다면선형대수 101의 내적: a · b = a₁b₁ + a₂b₂ + ⋯. 같은 방향이면 크고, 직각이면 0이에요.

조금 더 정확하게

1초에 fs번 잰 샘플 x₀, …, xN−1이 있으면 Xk = Σ xₙe−i2πkn/N입니다. 오일러 공식으로 풀면 ‘신호와 cos의 내적’이 실수부, ‘신호와 sin의 내적’의 음수가 허수부예요. k번째 칸은 N개 샘플 동안 k번 도는 화살표이니 실제 주파수는 k · fs/N Hz이고, 칸 사이 간격 fs/N이 주파수 해상도입니다. 1초를 재면 1 Hz 간격, 0.1초를 재면 10 Hz 간격이에요. 더 촘촘히 보려면 더 오래 재야 합니다.

기준 사인파들은 서로 직교합니다. 다른 칸끼리 내적하면 정확히 0이에요. 그래서 진폭 A, 진동수가 정확히 k칸인 사인파는 Xk와 XN−k(13단계의 반대로 도는 짝)에 |X| = AN/2씩 나타나고 다른 칸은 0입니다. 반대로 X를 모두 알면 역변환으로 신호를 그대로 되살릴 수 있어요. 정보는 하나도 사라지지 않고 보는 방향만 바뀝니다.

진동수가 칸 사이(예: 5.5칸)에 걸리면 N개 샘플 안에 주기가 딱 맞게 들어가지 않아 끝이 끊기고, 그 끊김 때문에 이웃 칸으로 에너지가 새어 나갑니다(누설). 신호 양 끝을 0으로 부드럽게 줄이는 한 창(Hann window)을 곱하면 멀리 새는 누설이 크게 줄어요. 대신 봉우리가 조금 넓어지고 낮아집니다.

이산 푸리에 변환
(28)
  1. 1DFT. 신호를 거꾸로 k번 도는 화살표에 실어 모두 더하기. 원에 감긴 점들의 무게중심의 N배예요.
  2. 2풀어 쓰면 내적 두 개. cos과의 내적, sin과의 내적. 어느 위상의 사인파든 놓치지 않으려고 둘 다 잽니다.
  3. 3칸 k의 뜻. 실제 주파수는 k·fs/N, 사인파의 진폭은 2|Xk|/N입니다(0번 칸은 |X₀|/N이 평균).
직교성과 역변환
(29)
  1. 1직교성. 같은 화살표끼리면 N, 다르면 한 바퀴에 고르게 퍼져 0. DFT가 성분을 깔끔하게 가르는 이유예요.
  2. 2역변환. 화살표들을 다시 더하면 원래 신호. 18단계의 필터는 X를 고친 뒤 이걸로 되돌립니다.
파이썬
import numpy as np

fs, N = 64, 64                               # 64 Hz로 1초
n = np.arange(N)
x = 1.0 * np.sin(2*np.pi*5*n/fs) + 0.5 * np.cos(2*np.pi*12*n/fs)

def dft(x):                                  # 정의 그대로, O(N^2)
    N = len(x)
    k = np.arange(N)[:, None]
    W = np.exp(-2j * np.pi * k * np.arange(N) / N)   # 기준 화살표 표
    return W @ x                             # 행마다 내적

X = dft(x)
print(np.allclose(X, np.fft.fft(x)))         # True
freqs = np.arange(N) * fs / N                # 칸 → Hz
amp = 2 * np.abs(X[:N//2]) / N               # 5 Hz → 1.0, 12 Hz → 0.5
w = np.hanning(N)                            # 누설을 줄이는 창
Xw = np.fft.fft(x * w)

해 볼 것

  • 성분 1의 진동수를 5.5로 바꾸면 봉우리 양옆 칸들도 높아집니다. 누설이에요. [한 창]을 켜면 멀리 있는 칸들이 크게 낮아집니다.
  • 잡음을 키워도 5 Hz와 12 Hz 봉우리는 바닥 위로 뚜렷이 남습니다. 시간 그래프로는 안 보이던 성분이 주파수로는 보여요. 잡음은 모든 칸에 고르게 퍼지지만 사인파는 한 칸에 모이기 때문입니다.

핵심

DFT는 신호를 주파수마다의 기준 화살표와 내적해 그 성분의 세기와 위상을 잽니다. 칸 k는 k·fs/N Hz이고, 해상도를 높이려면 오래 재야 해요. 칸 사이 주파수는 누설을 만들고 창 함수가 그걸 줄입니다.

너무 드물게 재면 다른 신호로 보인다: 샘플링과 앨리어싱

쓰인 곳PID 실습의 제어 주기드론의 1 kHz 각속도 루프카메라와 라이다의 프레임15단계의 DFT
먼저, 수식 없이

영화 속 마차 바퀴가 거꾸로 도는 걸 본 적이 있나요? 카메라는 1초에 24장만 찍는데, 그 사이에 바퀴살이 거의 한 칸을 돌면 다음 장에서는 살짝 뒤로 간 것처럼 보입니다. 띄엄띄엄 재면 빠른 움직임이 엉뚱한 느린 움직임으로 둔갑해요. 이것이 앨리어싱입니다.

로봇 센서도 모두 띄엄띄엄 잽니다. IMU는 1초에 수백~수천 번, 카메라는 30번, 라이다는 10~20바퀴. 규칙은 하나예요. 보고 싶은 가장 빠른 떨림보다 두 배 넘게 자주 재야 합니다(나이퀴스트 조건). 1초에 100번 재는 센서로는 50 Hz까지만 제대로 보여요.

그보다 빠른 떨림은 사라지지 않고 가짜 느린 떨림으로 섞여 들어옵니다. 드론 모터가 120 Hz로 떨고 그 신호를 100 Hz로 읽으면 20 Hz짜리 가짜 흔들림이 보이고, 제어기는 그걸 진짜로 믿고 반응해요. 그래서 센서는 재기 전에 빠른 떨림을 먼저 걸러 내는 필터(앤티앨리어싱 필터)를 둡니다.

한 줄로샘플링 주파수의 절반(나이퀴스트 주파수)보다 빠른 떨림은 느린 가짜 떨림으로 접혀 보입니다. 재기 전에 걸러 내거나 더 자주 재야 해요.

샘플링 주파수 fs
1초에 몇 번 재나.
나이퀴스트 주파수
fs/2. 제대로 볼 수 있는 한계.
앨리어싱
빠른 떨림이 느린 가짜 떨림으로 보이는 것.
앤티앨리어싱 필터
재기 전에 fs/2 위를 걸러 내는 필터.

까먹었다면주파수 f와 주기 T는 역수예요. f = 50 Hz면 T = 0.02초. fs = 100 Hz면 0.01초마다 한 번 잽니다.

조금 더 정확하게

fs로 재면 샘플 시각은 tₙ = n/fs입니다. 이 시각들에서 sin(2πft)와 sin(2π(f + fs)t)는 정확히 같은 값이에요. 2πfstₙ = 2πn이라 샘플마다 한 바퀴씩 더 돌 뿐이니까요. 그래서 f와 f ± fs, f ± 2fs…는 샘플로는 구분할 수 없고, 우리가 보는 것은 그중 가장 느린 |f − fs·round(f/fs)|입니다. 주파수 축을 fs/2에서 접고 또 접는 모양이라 ‘접힘’이라고도 해요.

그래서 fs/2(나이퀴스트 주파수) 아래의 신호만 제대로 볼 수 있고, DFT 결과도 0~N/2칸까지만 새 정보이며 나머지는 거울상입니다. 조건 fs > 2fmax를 지키면, 놀랍게도 샘플만으로 원래 연속 신호를 완벽히 되살릴 수 있어요(샘플링 정리).

제어 루프도 샘플링입니다. PID 실습 3장에서 10 Hz로 돌린 제어기가 같은 게인에 떨고 50 Hz에서 매끄러웠던 것, 드론 각속도 루프를 1 kHz로 돌리는 것은 모두 ‘제어하려는 움직임보다 충분히 자주 보고 고쳐야 한다’는 같은 이야기예요. 보통은 제어할 대역의 10배 이상으로 잡습니다.

샘플링과 앨리어싱
(30)
  1. 1샘플 시각. Ts = 1/fs마다 한 번. 그 사이는 모릅니다.
  2. 2나이퀴스트 조건. 가장 빠른 성분보다 두 배 넘게 자주 재야 해요. 한 주기에 적어도 두 번 넘게.
  3. 3보이는 주파수. fs의 정수배를 빼서 가장 작아진 값. 120 Hz를 100 Hz로 재면 |120 − 100| = 20 Hz로 보여요.
파이썬
import numpy as np

def apparent(f, fs):                       # 샘플로 보이는 주파수
    return abs(f - fs * np.round(f / fs))

print(apparent(120, 100))                  # 20 Hz: 모터 진동이 가짜 흔들림으로
print(apparent(30, 100))                   # 30 Hz: 나이퀴스트(50) 아래라 그대로
print(apparent(23.5, 24))                  # 0.5 Hz: 바퀴가 아주 느리게 도는 듯

fs, f = 100, 120
t = np.arange(0, 0.2, 1/fs)
a = np.sin(2*np.pi*f*t)                    # 120 Hz를 100 Hz로 잼

print(np.allclose(a, b))                   # True: 샘플로는 구분 불가

  • [모터 120 Hz를 100 Hz로]를 누르면 샘플이 20 Hz 사인파 위에 정확히 놓입니다. 이 샘플만 받은 제어기는 120 Hz 진동을 20 Hz 흔들림으로 알아요.
  • [거꾸로 도는 바퀴]에서 바퀴 속도를 바꿔 보세요. 살이 4개라 1/4바퀴마다 같은 모습이 되므로, 초당 회전수가 프레임 수의 1/4에 살짝 못 미치면 거꾸로, 딱 맞으면 멈춰, 살짝 넘으면 느리게 앞으로 도는 것처럼 보입니다.

핵심

샘플링하면 fs/2보다 빠른 떨림은 느린 가짜 떨림으로 접혀 보입니다. 보고 싶은 가장 빠른 성분의 두 배보다 자주 재고, 그보다 빠른 성분은 재기 전에 걸러 내세요. 제어 주기도 같은 원리입니다.

반으로 나눠 다시 쓴다: FFT

쓰인 곳자료구조·알고리즘의 분할 정복numpy의 np.fft18단계의 필터와 합성곱
먼저, 수식 없이

DFT를 정의대로 계산하면 칸 N개 각각에 샘플 N개를 곱해 더하니 N²번의 곱셈이 필요합니다. 1 kHz로 1초 동안 잰 1024개면 백만 번, 4096개면 천7백만 번이에요. 로봇이 매 순간 하기엔 무겁습니다.

1965년 쿨리와 튜키가 널리 알린 FFT(고속 푸리에 변환)는 합병 정렬과 같은 꾀를 씁니다. 샘플을 짝수 번째와 홀수 번째로 나눠 각각 절반 크기의 DFT를 하고, 두 결과를 회전 인자 하나만 곱해 합쳐요. 절반 크기 DFT도 또 반으로 나누고… 1개짜리까지 내려가면 끝입니다. 단계는 log₂N개, 단계마다 N번 정도의 계산이라 전체는 N log₂N. 1024개면 백만 번이 만 번 남짓으로 줄어요.

핵심은 ‘한 번 계산한 걸 두 번 쓴다’입니다. 절반짜리 결과 Ek, Ok 한 쌍으로 Xk와 Xk+N/2 두 칸을 같이 만들어요. 더하면 하나, 빼면 다른 하나. 이 X자 모양 계산을 나비라고 부릅니다.

한 줄로FFT는 DFT와 똑같은 답을 분할 정복으로 N log N번 만에 냅니다. 짝·홀로 나누고, 나비 하나로 두 칸을 같이 만들어요.

까먹었다면합병 정렬은 반으로 나눠 각각 정렬하고 합칩니다. T(N) = 2T(N/2) + O(N)이라 O(N log N)이에요(자료구조·알고리즘).

조금 더 정확하게

N이 2의 거듭제곱일 때, DFT의 합을 짝수 번째 샘플과 홀수 번째 샘플로 나누면 각각이 길이 N/2짜리 DFT Ek, Ok가 되고, 홀수 쪽에만 WNk = e−i2πk/N이 곱해집니다. 그리고 WNk+N/2 = −WNk(반 바퀴 더 돌면 반대 방향)이라 Xk+N/2 = Ek − WkOk가 공짜로 나와요. 길이 N 문제 하나를 길이 N/2 문제 두 개와 나비 N/2개로 바꾼 거예요.

되풀이해서 나누다 보면 입력 순서가 섞입니다. 8개라면 0, 4, 2, 6, 1, 5, 3, 7. 인덱스를 2진수로 쓰고 비트를 거꾸로 읽은 순서(비트 뒤집기)예요. 실제 구현은 재귀 대신 이 순서로 한 번 섞고, 2개짜리, 4개짜리, 8개짜리 나비를 차례로 제자리에서 계산합니다.

N이 2의 거듭제곱이 아니면 뒤에 0을 채워 늘리거나(zero padding), 3이나 5로 나누는 변형을 씁니다. numpy의 np.fft.fft, 마이크로컨트롤러용 CMSIS-DSP가 모두 FFT예요. 결과는 정의대로 계산한 DFT와 반올림 오차 범위에서 똑같습니다. 알고리즘만 빨라졌을 뿐 수학은 그대로예요.

짝·홀로 나누기
(31)
  1. 1짝·홀로 나누기. 짝수 번째 샘플의 DFT Ek, 홀수 번째의 DFT Ok. 둘 다 길이 N/2예요.
  2. 2나비. 한 쌍(Ek, Ok)에 Wk를 한 번 곱해 두 칸을 만듭니다. 더하면 앞쪽, 빼면 뒤쪽.
  3. 3합병 정렬과 같은 점화식. 단계 log₂N개 × 단계마다 N. 1024개면 백만 번이 약 만 번으로.
파이썬
import numpy as np

def fft(x):                                   # 재귀 FFT (len(x)는 2의 거듭제곱)
    N = len(x)
    if N == 1:
        return x.astype(complex)
    E = fft(x[0::2])                          # 짝수 번째
    O = fft(x[1::2])                          # 홀수 번째
    W = np.exp(-2j * np.pi * np.arange(N // 2) / N)   # 회전 인자
    return np.concatenate([E + W * O,         # 나비: 더하면 앞쪽 칸
                           E - W * O])        #       빼면 뒤쪽 칸

x = np.random.randn(1024)
print(np.allclose(fft(x), np.fft.fft(x)))     # True

def bit_reverse(i, bits):                     # bits=3: 0,4,2,6,1,5,3,7
    return int(format(i, f'0{bits}b')[::-1], 2)

핵심

FFT는 DFT를 짝·홀로 반씩 나눠 다시 쓰는 분할 정복입니다. 나비 하나가 두 칸을 같이 만들어 N²이 N log N이 되고, 답은 DFT와 똑같아요.

주파수에서 지우고, 곱하고, 되돌린다: 필터와 합성곱

쓰인 곳PID의 D 필터4단계의 지수 이동 평균베이즈 필터의 이동 갱신(합성곱)
먼저, 수식 없이

드론의 기울기 신호에는 진짜 기울기 변화(느린 출렁임)와 모터 진동(빠른 떨림), 잡음이 섞여 있습니다. 시간 그래프로는 엉켜 있지만 주파수로 바꾸면 느린 것은 왼쪽, 모터 진동은 오른쪽 한 칸에 따로 서 있어요. 오른쪽 칸들을 0으로 지우고 역변환으로 되돌리면 느린 출렁임만 남습니다. 이것이 주파수 영역의 필터예요.

4단계의 지수 이동 평균(PID의 D 필터)도 사실 같은 일을 합니다. 빠른 떨림은 줄이고 느린 변화는 통과시키는 저역 통과 필터예요. 다만 지난 값만 쓰니 실시간으로 돌릴 수 있는 대신 출력이 조금 늦습니다. FFT 필터는 구간 전체를 본 뒤에 처리하니 늦지는 않지만, 미래 값까지 써야 해서 주로 기록된 데이터를 분석할 때 씁니다.

베이즈 필터의 이동 갱신도 주파수와 이어져요. ‘한 칸 앞으로, 조금 흐리게’는 믿음 막대그래프를 이동 모델로 문지르는 합성곱이었습니다. 합성곱은 칸마다 N번씩 곱해 더하니 N²이지만, 주파수로 가면 칸끼리 한 번씩 곱하면 끝이에요. FFT로 갔다가 곱하고 돌아오면 N log N입니다.

한 줄로신호를 FFT로 주파수로 바꿔 원하지 않는 칸을 지우고 되돌리면 필터가 됩니다. 시간에서의 합성곱은 주파수에서의 곱셈이에요.

조금 더 정확하게

주파수 영역 필터는 세 단계입니다. X = FFT(x)로 바꾸고, 칸마다 마스크 Hk를 곱하고(지울 칸은 0, 남길 칸은 1), y = IFFT(H · X)로 되돌려요. 차단 주파수 위를 지우면 저역 통과, 특정 대역만 지우면 노치 필터입니다. 실수 신호의 스펙트럼은 k와 N − k가 짝이라 마스크도 짝을 맞춰 줘야 결과가 실수로 돌아옵니다(numpy의 rfft는 이걸 알아서 해 줘요). 마스크를 칼같이 자르면 시간 신호에 잔물결이 생겨서, 실제로는 경계를 부드럽게 줍니다.

합성곱 (b * g)ₙ = Σ bmgn−m은 b의 칸마다 g 모양을 옮겨 찍어 더하는 것입니다. 이동 모델 g가 ‘2칸 앞으로, 양옆으로 조금 퍼짐’이면 믿음 b가 그대로 2칸 밀리고 흐려져요. 합성곱 정리는 FFT(b * g) = FFT(b) · FFT(g)라는 것입니다. 끝이 반대쪽으로 감기는 원형 합성곱일 때 정확히 성립하고, 감기지 않게 하려면 0을 채워 늘려요.

지수 이동 평균, PID의 D 필터, 이미지 흐림, CNN의 합성곱 층도 모두 합성곱입니다. 짧은 필터는 시간 영역에서 바로 하는 편이 빠르고, 긴 필터나 큰 격자(예: 2D 점유 격자 전체를 흐리기)는 FFT가 훨씬 빨라요.

주파수에서 거르기와 합성곱 정리
(32)
  1. 1주파수 필터. 바꾸고, 칸마다 곱하고, 되돌리기. Hk가 남길 칸과 지울 칸을 정해요.
  2. 2합성곱. b의 칸마다 g를 옮겨 찍어 더하기. 칸 N개마다 N번이라 N².
  3. 3합성곱 정리. 시간에서의 합성곱이 주파수에서는 칸끼리의 곱 한 번. FFT 두 번, 곱 N번, 역FFT 한 번이면 N log N이에요.
파이썬
import numpy as np

fs, N = 256, 512                            # 256 Hz로 2초
t = np.arange(N) / fs
slow = 0.3 * np.sin(2*np.pi*0.5*t)          # 진짜 기울기 변화
x = slow + 0.15*np.sin(2*np.pi*37*t) + 0.05*np.random.randn(N)

X = np.fft.rfft(x)                          # 실수 신호용 FFT (0~fs/2)
f = np.fft.rfftfreq(N, 1/fs)
X[f > 5] = 0                                # 5 Hz 위를 지운다
y = np.fft.irfft(X, n=N)                    # 되돌리기
print(np.std(y - slow), np.std(x - slow))   # 약 0.01 vs 0.12

belief = np.zeros(64); belief[20] = 0.6; belief[40] = 0.4
kernel = np.zeros(64); kernel[[1, 2, 3]] = [0.2, 0.6, 0.2]  # 2칸 앞, 퍼짐
direct = np.array([sum(belief[m] * kernel[(n - m) % 64] for m in range(64))
                   for n in range(64)])     # O(N^2)
via_fft = np.fft.ifft(np.fft.fft(belief) * np.fft.fft(kernel)).real
print(np.allclose(direct, via_fft))         # True

상태 x = (각도 θ, 각속도 ω)인 감쇠 진자는 θ̇ = ω, ω̇ = −(g/L)sin θ − cω입니다. 평형점은 ω = 0, sin θ = 0인 θ = 0(바닥)과 θ = π(꼭대기)예요. 바닥에서 야코비안 J = [[0, 1], [−g/L, −c]]의 고유값은 실수부가 −c/2로 음수라 안정(감쇠 진동)이고, 꼭대기에서는 J = [[0, 1], [g/L, −c]]이라 양의 고유값이 하나 있어 불안정입니다.

선형화로는 안 보이는 것도 있습니다. 반데르폴 진동자처럼 평형점은 불안정한데 바깥에서는 안쪽으로 끌려와서, 결국 정해진 크기의 고리를 영원히 도는 리밋 사이클이 생기기도 해요. 4족 로봇의 걸음 리듬을 만드는 중앙 패턴 생성기(CPG)가 이런 리밋 사이클을 씁니다. 포식자-피식자 모형처럼 평형점 둘레를 닫힌 궤도로 도는 보존계도 있고요.

M&S에서 위상 평면은 ‘이 모형이 어떤 행동을 할 수 있나’를 시뮬레이션 전에 미리 보는 도구입니다. 평형점과 그 안정성, 고리의 존재를 먼저 알면, 시뮬레이션 결과가 이상할 때 모형 탓인지 적분기 탓인지(수치해석 101) 가려내기 쉬워요.

평형점과 선형화
(33)
  1. 1평형점. 흐름 f가 0인 점. 그 자리에 놓으면 영원히 머물러요.
  2. 2평형점 근처의 선형화. 벗어난 양 δ의 변화를 야코비안 J로 근사합니다.
  3. 3안정의 판정. 고유값의 실수부가 모두 음수면 작은 흔들림이 사라져요.

import numpy as np
from scipy.integrate import solve_ivp

g_L, c = 9.81, 0.3
f = lambda t, s: [s[1], -g_L * np.sin(s[0]) - c * s[1]]       # 감쇠 진자

for theta0, w0 in [(1.0, 0.0), (0.0, 6.5), (np.pi - 0.01, 0.0)]:
    sol = solve_ivp(f, [0, 20], [theta0, w0], max_step=0.02)
    print(theta0, w0, '->', sol.y[0, -1] % (2 * np.pi))       # 어느 바닥에 멈췄나

for name, theta in [('바닥', 0.0), ('꼭대기', np.pi)]:
    J = np.array([[0, 1], [-g_L * np.cos(theta), -c]])        # 평형점의 야코비안
    print(name, np.linalg.eigvals(J))                          # 실수부 부호로 안정 판정

쓰인 곳12단계의 미분방정식과 RK42단계의 지수와 로그로켓 착지·발사 시뮬레이션시뮬레이션 101의 모형 세우기
먼저, 수식 없이

로켓은 연료를 뒤로 뿜어 그 반작용으로 나아갑니다. 그런데 연료를 태울수록 로켓이 가벼워져서, 같은 추력이라도 갈수록 더 빨리 가속해요. 질량이 시간에 따라 변하니 뉴턴의 F = ma를 그대로 쓸 수 없고, 질량도 미분방정식의 상태가 됩니다.

연료를 다 태웠을 때 얻는 속도에는 유명한 공식이 있어요. 중력과 공기가 없다면 Δv = ve ln(처음 질량 ÷ 마지막 질량). 2단계의 로그가 여기서 나옵니다. 연료를 두 배로 실어도 속도는 두 배가 안 되는 이유예요. 늘린 연료를 들어 올리는 데 또 연료가 드니까요.

실제 비행에서는 중력이 내내 끌어내리고(중력 손실), 공기가 저항합니다(항력 손실). 공기는 높이 올라갈수록 지수적으로 엷어지고 항력은 속도의 제곱에 비례해서, 어느 높이에서 공기 압력이 가장 큰 순간(max-Q)이 생겨요. 로켓 구조가 견뎌야 하는 가장 힘든 순간이라 발사 시뮬레이션에서 꼭 확인합니다.

한 줄로로켓은 질량이 줄어드는 미분방정식으로 모델링합니다. 이상적인 속도 증가는 ve ln(m₀/mf)이고, 실제로는 중력과 항력이 그만큼을 깎아요.

조금 더 정확하게

추력 T로 질량 흐름 ṁ = −T/ve만큼 연료를 태우면, 속도는 mv̇ = T − mg − D로 바뀝니다. 중력과 항력이 없으면 v̇ = (T/m), dm = −(m/ve)dv를 적분해 Δv = ve ln(m₀/mf)가 나와요(11단계의 원시함수 1/m → ln m). 같은 Δv에 필요한 질량비가 지수적으로 커지기 때문에, 로켓을 여러 단으로 나눠 빈 탱크를 버리는 다단식이 쓰입니다.

공기 밀도는 대략 ρ(h) = ρ₀e−h/H(H ≈ 8.5 km)이고, 항력은 D = ½ρCdAv|v|입니다. 처음에는 속도가 작아 항력이 작고, 높이 올라가면 공기가 엷어져 다시 작아지니 그 사이에 동압 q = ½ρv²의 최댓값(max-Q)이 생겨요. 실제 발사에서는 이 근처에서 추력을 잠시 줄이기도 합니다.

이 모형은 상태 (h, v, m) 세 개의 미분방정식이고, 연료가 바닥나는 순간(사건)에 식이 바뀝니다. 그래서 수치해석 101 10단계의 사건 찾기와 적응 간격이 그대로 쓰이고, 바람·추력 흔들림을 넣어 착지 분산을 보는 것이 확률과 통계 101 23단계의 몬테카를로예요. 실습은 RK4로 Δt = 0.05초씩 적분합니다.

질량이 변하는 로켓
(34)
  1. 1운동과 질량. 추력에서 중력과 항력을 뺀 힘이 지금 질량을 가속하고, 질량은 추력에 비례해 줄어요.
  2. 2지수 대기. H ≈ 8.5 km마다 공기 밀도가 e분의 1로 엷어져요.
  3. 3로켓 방정식. 중력·항력이 없을 때의 속도 증가. 실제 값과의 차이가 손실입니다.
파이썬
import numpy as np
from scipy.integrate import solve_ivp

T, ve, g, CdA = 25_000.0, 2500.0, 9.81, 0.3        # 추력 N, 배기 속도 m/s, 항력 면적
m_dry, m_fuel = 300.0, 700.0
rho = lambda h: 1.225 * np.exp(-max(h, 0) / 8500)

def rhs(t, s):
    h, v, m = s
    burning = m > m_dry
    thrust = T if burning else 0.0
    drag = 0.5 * rho(h) * CdA * v * abs(v)
    return [v, (thrust - m * g - drag) / m, -thrust / ve if burning else 0.0]

burnout = lambda t, s: s[2] - m_dry; burnout.terminal = True   # 연료가 다 떨어지는 사건
sol = solve_ivp(rhs, [0, 300], [0, 0, m_dry + m_fuel], events=burnout, max_step=0.05)
v_bo = sol.y[1, -1]
print('연소 종료 속도', v_bo, '이상적', ve * np.log((m_dry + m_fuel) / m_dry))
q = 0.5 * np.array([rho(h) for h in sol.y[0]]) * sol.y[1]**2
print('max-Q', q.max(), '고도', sol.y[0, q.argmax()])
