로보틱스 · 모델링과 시뮬레이션(M&S) 보조 자료

로봇과 Sim을 움직이는 수학, 여섯 권

로봇 수업과 모델링·시뮬레이션(M&S)에 나오는 수학을 여섯 페이지로 나눠 모았습니다. 모든 단계가 ‘수식 없이 먼저’ 설명하고, 같은 내용을 식과 파이썬 코드로 적은 뒤, 직접 움직여 보는 실습으로 끝나요. 고등학교에서 미적분을 배우지 않았어도 처음부터 따라올 수 있게 썼습니다.

여섯 권

카드의 [단계 목록]을 펼치면 단계마다 바로 가는 링크가 있습니다. 각 페이지 맨 위의 ‘수학 101 시리즈’ 줄로 언제든 다른 권으로 넘어갈 수 있어요.

읽는 순서

처음이라면 왼쪽에서 오른쪽으로 읽으세요. 가운데 두 권은 순서가 없고 서로 자주 오갑니다. 오른쪽은 필요할 때 펼쳐 보는 심화편이고, 시뮬레이션 101은 M&S를 하려면 꼭 거쳐야 하는 권이에요.

단계 찾기

여섯 권의 단계 제목과 핵심어에서 찾습니다. ‘칼만’, ‘야코비안’, ‘FFT’처럼 실습에서 본 낱말을 넣어 보세요.

모든 단계는 같은 순서로

여섯 권 모두 단계마다 같은 다섯 칸으로 되어 있어서, 한 권을 읽어 보면 나머지도 같은 방식으로 읽을 수 있습니다.

먼저, 수식 없이비유와 로봇 이야기로 무엇을 왜 하는지
조금 더 정확하게같은 이야기를 식으로
수식 카드와 파이썬번호 주석이 달린 식과 짧은 코드
실습직접 끌고 바꿔 보는 그림
해 볼 것과 핵심무엇을 확인할지, 한두 문장 요약
각 페이지는 브라우저에서 바로 동작합니다. 실습의 계산은 모두 페이지 안에서 이루어지고 따로 설치할 것은 없어요.
