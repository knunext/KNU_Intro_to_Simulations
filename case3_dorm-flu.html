A3기숙사 독감: 같은 질문, 두 모델

기숙사 한 곳에서 독감 환자가 둘 생겼습니다. 대책이 없으면 몇 명이 앓을까요? 증상자를 격리하는 것과 층 휴게실을 닫는 것 중 무엇이 나을까요? 같은 질문을 6편의 시스템 다이내믹스(SD)와 3편의 에이전트 기반 모델(ABM)로 풀고, 두 모델이 어디서 같은 답을 내고 어디서 갈라지는지 봅니다.

이 사례에서 해 볼 것

  • 같은 감염 과정을 접촉 구조가 있는 ABM과 고루 섞인 SD로 각각 적습니다.
  • 같은 매개변수에서 두 모델의 유행 크기와 정점 시기가 왜 다른지 설명합니다.
  • ABM의 반복 실행으로 "초기에 저절로 꺼지는" 유행의 비율을 재고, SD가 말해 주지 못하는 것을 확인합니다.
  • SD를 ABM에 맞춰 보정한 뒤에도 정책 효과의 예측이 갈라지는 지점을 찾습니다.
  • 5절에서 학생마다 다른 일과(수업, 식사, 샤워, 휴게실, 엘리베이터) 위에 감염을 얹고, 검사 방식과 격리 프로토콜을 바꿔 가며 비교합니다.

1질문과 개념 모델

감염의 단계는 두 모델이 같고, 다른 것은 누가 누구를 만나느냐뿐입니다.

1.1질문 정하기단계 1

결정해야 할 것은 둘입니다. 대책이 필요한가, 필요하다면 증상자 격리와 층 휴게실 폐쇄 중 무엇을 할까. 여기에 방법에 대한 질문이 하나 붙습니다. 6편에서 캠퍼스 독감을 SD로 풀어 보았는데, 기숙사처럼 방과 층으로 나뉜 곳에서도 그 답을 믿을 수 있을까?

1.2개념 모델단계 2

기숙사는 4개 동, 동마다 5층, 층마다 2인실 15개로 모두 600명입니다. 감염은 SEIR로 적습니다. 감염된 사람은 잠복(E, 평균 2일)을 거쳐 전파 가능(I, 평균 4일) 상태가 되었다가 회복(R)합니다. 시간은 하루씩 갑니다.

ABM에서는 전파 가능한 사람 한 명이 하루 동안 다음 확률로 각 사람을 감염시킵니다. 아래 표의 값에 전파력 s를 곱한 것입니다.

SD는 이 구조를 모릅니다. 모두가 모두와 고르게 섞인다고 보고, 하루 기대 감염자의 합 β = 0.77s만 씁니다. 감염 기간이 평균 4일이므로 기본 재생산수는 R0 = β × 4입니다. 기본값 s = 0.7이면 β = 0.54, R0 = 2.16입니다. 두 모델은 사람 한 명이 하루에 감염시킬 기대 인원이 같도록 맞춘 것입니다.

대책은 두 가지입니다. 증상자 격리는 전파 가능한 사람이 하루에 25% 확률로 발견되어 빈 방으로 옮겨지고, 그 뒤로는 아무도 만나지 않는 것입니다. 층 휴게실 폐쇄는 같은 층 접촉을 70%, 같은 동 접촉을 40% 줄입니다.

2데이터와 구현

잴 수 있는 것과 맞춰야 하는 것을 나누고, 두 모델을 같은 시간 축에서 돌립니다.

2.1데이터 모으기단계 3

잠복기와 감염 기간은 의학 문헌에서 가져옵니다. 접촉 구조는 설문(하루에 누구를, 어디서, 몇 분이나 만나는가)으로 얻을 수 있습니다. 와이파이 접속 기록처럼 더 정밀한 자료도 있지만 개인정보 동의 없이는 쓸 수 없습니다. 접촉 한 번당 감염 확률은 직접 잴 수 없으므로, 보건진료소의 일별 환자 수 같은 실제 유행 곡선에 모델을 맞춰 정합니다(8편의 보정). 이 사례에는 그런 자료가 없으므로, 아래 숫자는 결론이 아니라 두 모델의 차이를 보여 주는 실험입니다.

2.3검증과 타당성단계 5

검증. 매일 S, E, I, R의 합이 600인지, 잠복과 감염 기간의 평균이 2일과 4일인지 확인합니다. 더 강한 점검도 있습니다. 모든 접촉 확률을 같게 만들어 구조를 없애면 ABM 여러 번의 평균 곡선이 SD 곡선에 가까워져야 합니다. 같은 가정의 두 구현이 같은 답을 내는지 보는 것이므로, 어느 한쪽 코드의 실수를 잡아냅니다(연습 1).

타당성. 실제 기숙사 유행의 일별 환자 수가 있다면 곡선의 모양, 정점이 오는 날, 최종 감염 비율을 비교합니다. 숫자 하나가 아니라 여러 패턴을 함께 맞추는지가 중요합니다. 이 사례에는 그 비교가 빠져 있다는 점이 가장 큰 한계입니다.

3실험과 결정

ABM을 여러 번 돌려 분포를 만들고, SD 한 줄과 비교합니다.

3.1같은 매개변수, 두 모델단계 6

ABM 40번과 SD

가는 선 하나가 ABM 한 번의 전파 가능 인원입니다. 굵은 점선은 같은 매개변수의 SD, 가는 점선은 ABM의 평균 최종 감염률에 맞춰 β를 보정한 SD입니다.

기본값(s = 0.7, 대책 없음)에서 ABM을 100번 돌리면 평균 최종 감염률은 68.1% ± 5.2%p이고, 그중 13번은 열 명도 앓기 전에 꺼집니다. 같은 매개변수의 SD는 83.5%를 예측합니다. 정점도 다릅니다. 유행이 크게 번진 ABM 실행들은 평균 46일째에 58명으로 정점을 찍고, SD는 36일째에 72명입니다. SD가 더 크고 빠른 유행을 예측하는 것입니다.

이유는 접촉의 군집에 있습니다. 룸메이트 한 명, 층 사람 28명은 감염원이 가장 자주 만나는 사람들인데, 이들이 먼저 감염되거나 회복하면 그 감염원이 새로 옮길 사람이 빨리 바닥납니다. SD는 감염원이 언제나 600명 전체에서 고르게 새 사람을 만난다고 보므로 이 포화를 보지 못합니다.

3.2대책 비교단계 6

SD가 틀렸다면 보정하면 되지 않을까요? SD의 β를 ABM의 평균 최종 감염률(68.1%)이 나오도록 맞추면 R0가 2.16에서 1.67로 내려갑니다. 그 보정한 SD로 대책의 효과를 예측해 ABM과 비교합니다. 대책별 ABM은 같은 시드들을 써서(5편의 공통 난수) 차이만 보이게 했습니다.

3.3분석과 결정단계 7

결정. 이 모델에서는 두 대책 모두 최종 감염률을 열 배 넘게 줄이고, 둘의 효과는 비슷합니다. 그렇다면 비용으로 고릅니다. 증상자 격리에는 빈 방이 필요하고, 휴게실 폐쇄에는 학생들의 불편이 따릅니다. 필요한 격리실 수는 ABM에서 격리 중인 사람 수의 최댓값으로 셀 수 있습니다(연습 3). SD로는 셀 수 없는 숫자입니다.

방법에 대한 교훈. 같은 매개변수의 SD는 유행을 크게 과대평가했습니다. 보정한 SD는 훨씬 가까워지지만, 두 대책의 효과를 모두 작게 예측하고 특히 휴게실 폐쇄에서 차이가 큽니다(위 표에서 11.9% 대 6.2%). 보정값에도 민감합니다. 위젯의 40번처럼 기준 감염률이 조금 높게 나와 R0가 1.81로 보정되면, SD가 예측하는 대책 후 감염률이 두 배 가까이 뜁니다. 대책을 쓴 뒤의 재생산수가 1 근처라서 작은 차이가 크게 불어나기 때문입니다. SD에서는 휴게실 폐쇄가 "β를 층 접촉의 몫만큼 줄인다"로만 표현되는데, ABM에서 층 접촉은 방과 방을 잇는 다리라서 그것을 끊는 효과가 몫보다 큽니다. 또 SD는 유행의 절반 넘게가 초기에 저절로 꺼진다는 사실을 말해 주지 못합니다. 집단 전체의 평균이 궁금하고 섞임이 고른 곳이라면 SD가 빠르고 충분합니다. 누구와 누구가 만나는지가 대책의 대상이라면 ABM이 필요합니다.

4연결과 정리

4.1모델의 한계

강의실과 식당
기숙사 밖 접촉(수업, 식당, 동아리)은 "다른 동" 하나로 뭉뚱그렸습니다. 실제로는 이것이 동과 동을 잇는 주된 통로일 수 있습니다.
같은 사람들
모두의 감수성과 접촉량이 같습니다. 사람마다 접촉 수의 차이가 크면(마당발) 유행의 모양이 크게 달라집니다.
발견
증상은 모두 드러나고 발견 확률은 하루 25%로 일정합니다. 무증상 전파가 있으면 격리의 효과는 줄어듭니다.
하루 단위
하루 안의 순서(아침에 감염되어 저녁에 옮기는 일)는 무시했습니다.

4.2쓰인 편들

6편과 3편같은 SEIR을 저량과 유량으로, 개체와 접촉으로 적었습니다.

5편ABM은 실행마다 결과가 다르므로 반복과 신뢰구간으로 말하고, 대책 비교에는 같은 시드를 씁니다.

8편SD를 ABM에 맞춘 것은 보정이고, 보정한 모델이 보정에 쓰지 않은 상황(대책)에서도 맞는지 본 것은 타당성 확인입니다. 맞춘 상황에서만 맞는 모델은 과적합입니다.

4.3파이썬으로 확인하기

ABM과 SD를 같은 매개변수로 돌려 대책 없음과 휴게실 폐쇄를 비교합니다. 표준 라이브러리만 씁니다.

# dorm_flu.py : 기숙사 독감을 ABM과 SD로 같은 매개변수로 돌려 비교한다
import math, random, statistics as st

B, F, R = 4, 5, 15                     # 4개 동 × 5층 × 15실 × 2명 = 600명
N = B * F * R * 2
SIG, GAM = 0.5, 0.25                   # 하루에 E→I, I→R로 넘어갈 확률
BASE = {"room": 0.20, "floor": 0.012, "bldg": 0.0012, "all": 0.0002}

def rates(s, floor_closed=False):
    q = {k: v * s for k, v in BASE.items()}
    if floor_closed:
        q["floor"] *= 0.3; q["bldg"] *= 0.6
    return q

def abm(s, seed, floor_closed=False, days=120):
    rng = random.Random(seed)
    q = rates(s, floor_closed)
    room = [i // 2 for i in range(N)]
    flo = [r // R for r in room]
    bld = [r // (R * F) for r in room]
    state = [0] * N                    # 0=S, 1=E, 2=I, 3=R
    for i in rng.sample(range(N), 2):
        state[i] = 2
    infected = 2
    for _ in range(days):
        cr, cf, cb = [0] * (N // 2), [0] * (B * F), [0] * B
        for i in range(N):
            if state[i] == 2:
                cr[room[i]] += 1; cf[flo[i]] += 1; cb[bld[i]] += 1
        ca = sum(cb)
        if ca == 0 and 1 not in state:
            break
        new = state[:]
        for i in range(N):
            if state[i] == 0:          # 방, 층, 동, 나머지 순으로 노출된 횟수
                nr = cr[room[i]]; nf = cf[flo[i]] - nr
                nb = cb[bld[i]] - cf[flo[i]]; na = ca - cb[bld[i]]
                escape = ((1 - q["room"]) ** nr * (1 - q["floor"]) ** nf
                          * (1 - q["bldg"]) ** nb * (1 - q["all"]) ** na)
                if rng.random() > escape:
                    new[i] = 1; infected += 1
            elif state[i] == 1 and rng.random() < SIG: new[i] = 2
            elif state[i] == 2 and rng.random() < GAM: new[i] = 3
        state = new
    return infected / N

def sd(s, floor_closed=False, days=200):
    q = rates(s, floor_closed)          # 같은 접촉 강도를 고루 섞인 집단에 펼친다
    beta = q["room"] + 28 * q["floor"] + 120 * q["bldg"] + 450 * q["all"]
    S, E, I = N - 2.0, 0.0, 2.0
    for _ in range(days):
        new_e = S * (1 - math.exp(-beta * I / N))
        S, E, I = S - new_e, E + new_e - SIG * E, I + SIG * E - GAM * I
    return (N - S) / N, beta / GAM

s = 0.7
for closed, name in ((False, "대책 없음"), (True, "층 휴게실 폐쇄")):
    runs = [abm(s, seed, closed) for seed in range(30)]
    m, hw = st.mean(runs), 1.96 * st.stdev(runs) / math.sqrt(len(runs))
    fizzled = sum(r < 0.05 for r in runs)
    sd_attack, r0 = sd(s, closed)
    print(f"{name}: ABM {m:.1%} ± {hw:.1%} (30번 중 {fizzled}번은 초기에 꺼짐), "
          f"SD {sd_attack:.1%} (R0 = {r0:.2f})")
대책 없음: ABM 65.3% ± 10.6% (30번 중 5번은 초기에 꺼짐), SD 83.5% (R0 = 2.16)
층 휴게실 폐쇄: ABM 6.4% ± 3.4% (30번 중 22번은 초기에 꺼짐), SD 46.3% (R0 = 1.34)

실행 30번이라 신뢰구간이 위 표(100번)보다 넓습니다. 난수 생성기가 달라 숫자는 조금 다르지만 결론은 같습니다.

4.4연습과 확장

1. 파이썬 코드에서 네 가지 접촉 확률을 모두 같게(각 사람이 나머지 599명을 같은 확률로 만나도록) 바꾸면 ABM과 SD는 어떻게 될까요?

β가 같도록 확률을 0.77s/599로 두면, 유행이 번진 실행들의 평균 최종 감염률이 SD의 83.5%에 가까워집니다. 구조가 없으면 ABM은 SD의 확률 버전이 되기 때문입니다. 이것이 두 구현이 같은 가정에서 같은 답을 내는지 보는 검증입니다. 초기에 꺼지는 실행은 여전히 있습니다.

2. 기본 재생산수가 1을 넘는데도 유행이 저절로 꺼지는 이유는 무엇일까요?

처음 몇 명일 때는 감염이 우연에 크게 좌우됩니다. 첫 환자가 회복할 때까지 아무도 감염시키지 못할 확률이 작지 않고, 감염시킨 상대가 룸메이트뿐이면 그 방에서 끝나기도 합니다. 분기 과정 이론에 따르면 섞임이 고른 집단에서도 환자 한 명에서 시작한 유행이 꺼질 확률은 대략 1/R0 근처입니다. SD는 평균만 따라가므로 이 우연을 표현하지 못합니다.

3. 증상자 격리를 하려면 격리실이 몇 개 필요할까요? ABM을 어떻게 고쳐서 재야 할까요?

날마다 격리 중인 사람 수를 기록하고, 실행마다 그 최댓값을 구한 뒤, 여러 실행의 분포에서 95번째 백분위수를 고릅니다. 평균만큼 방을 준비하면 유행이 큰 해에는 모자랍니다. 1편의 M/M/c/K처럼 "방이 다 차면 어떻게 하는가"라는 규칙도 모델에 넣어야 합니다.

4. 6편의 캠퍼스 독감 모델을 이 사례에 맞춰 고친다면 무엇을 바꾸겠습니까?

동마다 저량을 따로 두고(S, E, I, R을 동별로), 동 안과 동 사이의 접촉률을 다르게 주는 구획 모델로 바꿀 수 있습니다. 그러면 SD도 구조의 일부를 표현하게 되어 ABM과의 차이가 줄어듭니다. 구획을 방까지 쪼개면 사실상 ABM이 됩니다. 어디까지 쪼갤지가 곧 모델 선택입니다.

5학생 160명의 일과 위에 쌓은 ABM

1~3절의 모델은 접촉을 확률표로 적었습니다. 이번에는 학생마다 시간표와 생활 습관을 주고, 실제로 강의실, 식당, 샤워실, 휴게실, 엘리베이터를 오가게 합니다. 감염은 같은 시간에 같은 곳에 있을 때만 일어납니다. 그 위에 검사와 격리 규칙을 따로 얹어, 규칙을 바꿔 가며 비교할 수 있게 만들었습니다.

5.1모델 구조

사람과 장소. 2개 동 × 4층 × 2인실 10개, 모두 160명입니다. 층마다 샤워실과 휴게실이 하나씩, 동마다 엘리베이터(정원 8명)와 1층 로비가 있고, 캠퍼스에는 강의실 6개, 학생식당, 모형 밖 장소(도서관 등)가 있습니다. 시간은 10분씩 갑니다.

일과. 학생마다 다른 성질을 가집니다. 일어나는 시각(평균 7시 45분, 표준편차 40분), 아침에 씻는지 저녁에 씻는지, 휴게실에 들르는 확률(10~90%), 엘리베이터를 타는 확률(2층 이상, 30~100%), 끼니를 거르지 않는 정도가 사람마다 다릅니다. 시간표는 24개 강좌 중 3~5개를 들으며, 강좌마다 요일(월수, 화목, 금), 시간대(9시부터 여섯 개), 강의실이 정해져 있어서 같은 강좌 학생들은 매주 같은 사람을 만납니다. 날마다 이 성질에서 하루 일정을 새로 뽑으므로, 모두가 같은 시각에 움직이지 않습니다. 기숙사 안과 밖을 오가는 순간 2층 이상 학생은 엘리베이터나 계단을 지나고, 같은 10분에 엘리베이터를 타려는 사람이 정원을 넘으면 로비에서 기다립니다.

감염. 같은 10분 동안 같은 장소에 있는 감수성자 i가 감염될 확률은 다음과 같습니다.

P(i 감염) = 1 − exp( −s · βℓ · mℓ2 · Δtℓ · Σj ∈ ℓ ιj )

s는 전체 전파력, βℓ는 장소 ℓ에서 감염원 한 명이 1분 동안 옆 사람을 감염시키는 세기, mℓ는 마스크 효과(쓰는 곳에서 0.5, 감염원과 감수성자 양쪽이 쓰므로 제곱), Δtℓ는 그 칸에서 함께 있는 시간(보통 10분, 엘리베이터 1분, 로비 3분), ιj는 같은 곳에 있는 사람 j의 감염력입니다.

병의 진행. 감염된 사람은 잠복(E, 감염력 0) → 증상 전(P, 감염력 0.8) → 증상(감염력 1, 이틀 뒤부터 0.5) 또는 무증상(A, 감염력 0.5, 35%) → 회복(R)을 거칩니다. 각 단계의 기간은 사람마다 로그정규분포에서 뽑습니다(평균 잠복 2일, 증상 전 1.5일, 증상과 무증상 4일). 증상이 생긴 사람의 60%는 수업과 휴게실에 가지 않고 방에 머물며, 끼니와 샤워는 절반쯤 계속합니다. 증상 전 단계의 사람은 자기가 아픈 줄 모르고 평소대로 다닙니다.

5.2시뮬레이터

기숙사 160명의 생활과 독감

회색 건강, 노랑 잠복, 주황 증상 전, 빨강 증상, 보라 무증상, 연한 색 회복. 빨간 테두리는 격리, 노란 테두리는 룸메이트 격리입니다. 건강한 학생을 누르면 감염되고, 감염 의심 학생을 누르면 신속항원 검사를 합니다(음성이 나올 수도 있습니다). 휴게실을 누르면 7일 닫습니다.

속도

속도를 1배로 두고 아침 8~9시를 보세요. 학생들이 일어나는 시각에 따라 하나둘 샤워실에 들렀다가, 수업 시간에 맞춰 엘리베이터를 타고 강의실로 흩어집니다. 저녁에는 일부만 휴게실로 모이고, 밤 9시 넘어 저녁에 씻는 사람들이 샤워실에 들어갑니다. 정책은 재생 중에 바꿔도 바로 적용되고, "처음부터"를 누르면 새 시드로 다시 시작합니다.

5.4모델을 넓히는 법

이 모델은 정책 실험을 늘려 가기 쉽게 네 부분으로 나눠 두었습니다. 페이지 소스의 dormabm 부분에 모두 있습니다.

장소 (DA.BETA, planDay)
새 장소는 β 값 하나와 일과에 들어가는 규칙 한 줄로 추가합니다. 예를 들어 세탁실, 편의점, 체육관. 샤워실을 시간대별로 나눠 쓰게 하는 규칙도 planDay에서 샤워 시각을 정하는 줄만 바꾸면 됩니다.
병의 진행 (DA.DIS)
단계별 기간 분포, 무증상 비율, 단계별 감염력. 실제 질병 자료로 바꿀 때 여기만 고칩니다.
검사 (DA.TEST, testing)
새 검사 종류는 단계별 민감도, 특이도, 결과 지연 세 가지로 정의합니다. 검사 일정(누가 언제 받는가)은 testing 함수에 한 갈래를 더하면 됩니다. 예를 들어 "증상이 생기면 신속항원, 음성이면 이틀 뒤 PCR 재검사", "룸메이트가 양성이면 3일 연속 신속항원" 같은 규칙입니다.
격리 프로토콜 (result, release)
양성이 나왔을 때 누구를 어디로 보내는지, 언제 풀어 주는지. 층 단위 격리, 격리실 정원과 대기, 격리 중 샤워 시간 분리 같은 규칙이 여기 들어갑니다.

5.5해 볼 것

  1. 어디서 옮나검사 없이 한 번 돌리고 읽음 줄의 "감염이 일어난 곳"을 보세요. 방이 가장 많고, 그다음은 엘리베이터, 샤워실, 휴게실, 강의실이 비슷합니다. 짧게 머물러도 좁고 붐비는 곳이 오래 머무는 넓은 곳만큼 중요합니다.
  2. PCR을 기다리는 하루"증상 시 신속항원"과 "증상 시 PCR"을 비교 실험에서 나란히 돌려 보세요. 정확도와 속도 중 무엇이 더 중요한지가 질병의 증상 전 기간에 달려 있다는 것을, DA.DIS의 P 기간을 바꿔 확인할 수 있습니다.
  3. 룸메이트를 어떻게 할까룸메이트를 그대로 두기, 함께 격리하기, 바로 검사하기를 비교하세요. 바로 검사하면 증상 전 단계의 룸메이트를 놓치기 쉽습니다(신속항원 민감도 35%).
  4. 매일 검사의 값매일 선별검사의 참여율 compliance를 0.8에서 0.4로 낮추면 감염률과 검사 수가 어떻게 바뀌는지, 위양성으로 격리된 학생이 몇 명인지 함께 보세요.
